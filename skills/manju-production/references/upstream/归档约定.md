# 作品归档约定

适用于新作品；已有项目继续使用其约定目录，不为套模板搬动用户文件。执行任务时读取实际项目约定，不要求项目已安装 AI-drwa 或已有 AGENTS.md。

```text
连载/<作品>/
  README.md                         # 原文范围、采用稿、当前阶段与待办
  正文/                             # 用户原文或授权创作的正文
  改编/第01集/
    剧本.md
    分镜脚本.md
    生成提示词.md
  资产/
    公共/
      视觉规范.md                   # 时代、画风、画幅、光线、已确认约束
      角色/<固定名>/设定.md          # 身份、服装状态、音色及素材路径
      道具/<固定名>/设定.md          # 结构、尺度、用途与状态
      场景/<固定名>/设定.md          # 布局、入口、固定设施、方向
    第01集/资产清单.md
  制作/第01集/
    导演规划与场记审查.md
    导演场记.json
    视频输入/EP01_整集输入/
      整集提示词.md
      素材清单.md
      素材/<固定名>.png
      补充状态参考/
      镜头首帧/EP01_B001_首帧.png
      镜头首帧/EP01_B001_尾帧.png
    视频/                           # 实际生成的片段与剪辑产物
    音频/                           # 实际配音、实测时长与声音记录
```

只创建本次阶段需要的目录和真实内容，不用空文件或空目录表示完成。正文章号和漫剧集号分别记录，不默认一章一集。

场次、生成节、镜头使用 `01-1`、`EP01_B001`、`EP01_S001`；镜头号整集连续，补镜可用 S001A，不重排已制作镜头。分镜、提示词及场记的播放顺序一致。每阶段一份当前稿，更新前读取现有内容，保留无关部分；历史追溯沿用项目已有版本管理。

公共资产只登记一份身份，换装、伤势、道具开合等属于状态，不能创建另一个人物或偷换工具。固定名使用 @资产名，输入包 `素材/` 的主 PNG 与其完全同名。三视图、四宫格属于参考板；状态图和镜头首尾帧不混进主素材。

制作记录的 `dest`、`refs` 用项目根相对路径；历史 `source` 只作来源追溯，继续制作使用项目内已归档的文件。清单写明实际模型/工具、参数、参考图用途、采用版本、候选/审核状态及已生成文件。没有实际调用结果时保持待定或待生成。

README 记录本次产物、采用稿、检查范围、缺失项和下一步。脚本通过仅表示机器检查范围内结构通过，不能替代用户确认、内容审查或画面/音频实测。作品和媒体保留在用户项目；本技能包不包含任何上游私有连载。
