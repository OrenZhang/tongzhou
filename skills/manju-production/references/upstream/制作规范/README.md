# 漫剧制作标准

这五份用户提供的模板共同构成本项目后续制作的标准。适用于所有连载，归档结构遵循根目录 [AGENTS.md](../归档约定.md)。`原始模板/` 保存模板源文件；全局题材规则直接维护在对应模板中，项目执行版只负责阶段流程、目录和格式适配，避免同一规则在多处重复维护。

## 规则优先与冲突处理

1. 用户当前明确要求优先。
2. 项目全局归档规则、本页明确适配规则及对应执行版优先于原始模板中的题材特例和矛盾格式。
3. 使用作品已确认的剧情、视觉、声音设定；其余沿用原始模板要求。
4. 保留原文事件、因果、人物关系、认知边界、结果和伏笔；配音真实时长、动作空间及资产稳定优先于华丽镜头。放不进10秒目标时拆节，不抢读或删除关键情节。

## 改编与节奏执行标准

- **正向价值**：将责任、互助、守信、专业、成长和承担等正向价值嵌入人物选择与行动，不用脱离剧情的口号替代冲突。
- **单节收束**：每个生成节必须有完整的小闭环，交代动作或信息的起点、推进和结束状态，方便独立生成、剪辑和承接下一节。
- **前30秒爽点**：前30秒内完成强危机、人物关系或能力反差的建立，并给出至少一个明确的爽点、反击、揭示或悬念。
- **节奏压缩**：整体节奏优先加快，压缩重复对白、重复动作和不改变因果的信息；允许缩短总时长，但不能删除关键因果、人物动机、反转结果或结尾悬念。
- **结构骨架**：整集优先采用“开头危机—中段反击—结尾更大危机”；中段反击必须由前文信息或人物能力触发，结尾危机必须提高代价、范围或任务难度。
- **爽点因果**：每个爽点必须写清触发原因、人物行动、结果反馈和后续影响，禁止无依据能力、偶然好运、角色降智或临时新增设定。
- **台词时间与剪辑余量（强制）**：每镜开头默认预留0.2—0.3秒建立起始构图与表演，再开始本镜对白；已有明确声音桥的连续对白可跨镜延续，但须标出来源和连续时码。对白、OS、旁白、画外音均按自然语速完整预算，计入呼吸、停顿和轮次间隔。最后一个字及其口型收束、关键动作完成后，至少保留0.2秒（建议0.3秒）自然结果停留再切镜；每个B节末尾也必须满足此要求，不能卡在最后一个字上结束。前后余量均计入镜头和生成节时长，留白期间只保留呼吸、环境音和动作余势，不追加台词、不冻结人物。可用发声时间＝镜头总时长－开镜余量－收尾余量－不能与对白同时发生的动作/停顿；问答按顺序累加，不能把多个角色的台词当作同时发声。时间不足时延长镜头或按完整语义拆节，不抢读、不截字、不挤占收尾；常规节仍尽量≤10秒，15秒为兼容上限。实际配音和生成视频须复核，实录超预算或句尾截断时重新调整，不以文本估算代替实测。
- **唯一最终稿**：每个阶段只维护一份最终稿，直接更新既定文件路径，不另存旧稿、副本或“最终版2”。资产源图的版本记录只服务于素材追溯，不能扩展为多份改编文稿。

本次采用以下明确适配：

- **现代题材适配**：模板2原始母版已改为时代中性规则；现代作品可按剧情使用手机、车辆、工业设备、现代建筑和现代光源，古代或幻想题材按各自作品设定执行。

- **题材**：古代历史战争为原模板特定项目背景，不是全局限制。《极寒纪元》按现代极寒末世处理，现代服装、车辆、设备照剧情保留。其他作品按其自身时代和世界观处理。
- **画风**：三份出图模板默认影视真人写实，除非用户或已有确认设定另有要求。统一记录在作品 `资产/公共/视觉规范.md`；不能把“漫剧”自动理解为必须二次元，也不能在已确认动漫风作品中强行真人化。ARRI/Cooke 等用语是风格参考，不是设备或生成质量保证。
- **画幅**：成片默认服务抖音竖屏，制作时在视觉规范明确实际画幅；人物设定板仍按模板使用16:9横版。场景四宫格的板式与成片画幅分开。
- **识别点**：重要角色须有稳定视觉区别，优先用已确认脸型、发型、体型、服装与配饰；不为防串脸擅加痣、疤、胎记、特殊武器等设定。原模板“必须唯一识别点”不意味着必须新加身体标记。
- **剧情顺序**：分镜沿用本次采用的剧本顺序；剧本允许在不破坏因果、认知和反转的范围内调整表达节奏，不提前挪入后续章剧情。既有倒叙或闪回明确标记，不强行改成时间正序。
- **格式**：采用执行版的“节—镜头”结构，统一资产、声音、运镜等字段，解决原模板格式重复和编号缺漏；不继续使用原模板重复的章节编号。
- **节长**：常规6—8秒，完整问答8—10秒，短动作或必要转场3—5秒，尽量不超过10秒；读不完则拆节，不抢读，不机械增加片段数量。15秒仅保留为旧工具兼容上限，不作为制作默认目标。
- **声音与字幕**：视频生成默认无BGM、无自动字幕，保留对白、内心声、画外音、环境音和动作音效。剧本中的必要字幕信息仍保留在分镜中，后期字幕与配乐按剪辑任务处理，不在生成画面中强制生成文字。
- **电话动作**：人物接电话时，必须按“响铃／取出手机→按下接听→贴到耳边并稳定→开始对白”的顺序写入分镜和生成提示词；不能在手机尚未贴耳时开始电话对白。
- **人物表情**：人物不默认全程严肃脸；根据危机、质疑、确认、恐惧、反击、迟疑和决断切换眉眼、眼神、嘴角、呼吸与下颌反应，允许适度夸张但保持真人写实，不做漫画变形或无依据的笑容。
- **道具文字**：默认无水印、Logo、无关标签；剧情必需的文字、刻度或读数不能删除，记录内容及后期添加方案。
- **空间尺度**：场景按故事真实尺度建立；木屋、走廊等不强制恢弘开阔。四机位必须来自同一空间，不能画成四套不同建筑。
- **资产引用**：`@名称`是项目稳定标识，不是任意模型都支持的控制语法。视频输入包中，`@资产名`必须与素材目录根目录的同名 `.png` 文件完全一致，例如 `@陈野`对应`陈野.png`；状态和版本信息只能放在 `补充状态参考/` 或内部归档源文件中。生成提示词记录实际参考图路径和工具素材绑定；纯文本输入时补充必要视觉锚点，不声称仅靠名称能锁定人物。
- **参考板与生产素材**：人物三视图、场景四宫格是参考板；白底道具图不等于透明底图。独立镜头、独立视角或透明合成素材按实际需求另做，确认采用后进入定稿。

## 跨文件统一约定

- 小说章号、漫剧集号的对应关系在剧本开头注明；不默认每章必须等于一集。目标时长在具体改编任务中确定并记录，缺失时依据内容提出明确建议，不虚构已确认时长。
- 场次使用 `01-1`；生成节使用 `EP01_B001`；镜头使用 `EP01_S001`。B是独立生成片段，S是整集镜头，不在每节重置镜头序号。
- 多镜头一节视频按 `EP01_B001_简述_v01.mp4` 命名；单镜头视频仍按 `EP01_S001_简述_v01.mp4`。分镜记录片段与镜头对应，节内时间从0开始。
- 资产使用固定 `@名称`，其名称、文件路径、状态和采用版本登记在各集 `资产清单.md`，实际资产源文件归公共目录。角色身份固定，换装、受伤等作为状态版本，不能重建为另一个角色。
- 稳定音色记录在角色 `设定.md`，本节情绪、音量和声音来源写在生成提示词。反复出现的群像按角色资产管理，面孔自然有差异，不复制主角。
- 场景布局与方向记录在场景 `设定.md`，人物、道具和环境的动态状态写入分镜。跨集延续状态注明在剧本或分镜中，不能仅依赖对话记忆。
- 生成提示词保存完整可复制的逐节文本；分镜保留制作安排与引用，不重复维护完整提示词。新增资产描述落在资产设定中，本集清单引用，不仅留在聊天里。
- 每个生成节的提示词必须是可独立执行的逐镜头文本，逐一写明本节每个镜头的时间、景别与运镜、人物动作和表情、对白/旁白/画外音、音效、实际资产及结束状态；只写“按分镜执行”、人物概述或节级摘要不算完成，不能交付视频制作。
- 每个生成节必须配套独立首帧和尾帧图：首帧对应本节第一个镜头的起始构图，尾帧对应最后一个镜头的结束状态，统一放在输入包 `镜头首帧/`，命名为 `EPXX_BXXX_首帧.png` 与 `EPXX_BXXX_尾帧.png`，并登记在素材清单。首尾帧只用于构图和时序承接，不参与 `@资产名` 主素材匹配；任一缺失时该节保持“待补齐”。
- 每集视频交付必须形成整集输入包：整集可复制提示词、与 `@资产名` 完全同名的主素材目录、补充状态参考目录和资产绑定清单；用户生成整集时不需要回到公共资产目录找图。
- 每集交付完成后必须执行“集后资产绑定审计”：逐项扫描分镜脚本和生成提示词中的 `@` 标识，核对固定资产登记、视频输入包根目录同名 PNG、状态参考目录、镜头首帧目录及临时别名。发现任何未匹配、误加 `@` 或目录混放时，该集保持“待补齐/待修正”，不能进入可直接生成状态；审计结论写入 `制作/资产绑定审计.md` 或该集审计记录。
- `EPXX_SXXX_*.png` 是镜头首帧/构图候选，单独放在 `镜头首帧/` 并按 B 节建立使用说明；它不属于【人物】【道具】【场景】资产，不参与 `@资产名` 同名匹配。
- 产出后更新连载 README 的索引、进度和采用版本。既有稿件不因规则建立而自动标记符合新标准或确认定稿。

## 执行范围

用户指定哪一阶段就执行哪一阶段。单纯读模板、维护规则或整理资料不自动改编、出图、调用视频模型。模板内“现在开始”“直接输出”等为未来阶段的执行说明，不会自行触发当前任务。

## 导演与场记执行步骤

分镜阶段执行[导演规划与场记审查](导演规划与场记审查.md)。导演先确定真实空间、人物调度、工具实体与动作落点；场记再逐镜核对前镜出口和后镜入口，区分文稿审查、结构检查与画面验证。五模板和全局约束优先，不整套叠加第三方默认规则。
