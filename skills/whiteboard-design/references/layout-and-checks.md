# 布局与验收

## 按内容安排

- 默认一条主阅读方向，纵向或横向均可。开始/结束使用椭圆，行动使用矩形，判断使用菱形；这是一套默认约定，用户已有图形风格优先。
- 文本以一到三行为宜；长句拆为节点名与备注。菱形内部可用宽度比矩形更小，必要时增大图形，不能仅让文字超过边框。
- 简单三节点图用一条主干，不加无意义分组。分支用“是/否”“成功/失败”等明确条件；多输入汇合避免重叠；回路在主干外侧绕行，标签靠近对应线段。
- 连线尽量不穿过其他节点，不让多个标签占同一点。使用折点绕行时 points 为相对坐标；不要将原生 `elbowed` 属性假装成当前工具支持的参数。
- 人物关系图：卡片用稳定角色 ID、名字和简短身份；关系有方向时用箭头，标签写可被来源支持的关系或事件。未知关系明确标为待确认；不要从外貌推断身份。角色设定/三视图/分镜图通过工作流媒体能力生成，再按真实可用导入能力关联。

## 持续修改的检查矩阵

| 请求                 | 必查结果                                             |
| -------------------- | ---------------------------------------------------- |
| 新建三节点流程       | 3 个形状、2 条双端绑定边，文字可编辑                 |
| 判断分支及汇合       | 每个条件有目的地，汇合边方向正确，标签不互换         |
| 登录重试/反馈回路    | 回边确实绑定回目标，折点不穿主干                     |
| 旧自由箭头修复       | 保留箭头 ID、颜色、标签和非必要不变的折点            |
| 更换连线目标         | 旧目标移除反向绑定，新目标只有一条该箭头引用         |
| 移动或缩放图形       | 两端点仍附着正确图形，标签跟随；检查旋转、菱形与椭圆 |
| 删除节点/连线        | 无指向已删除目标的绑定、无遗留容器文字               |
| 用户手改后 AI 接着改 | 未涉及元素保持原样，版本冲突不覆盖用户改动           |
| 保存重开/导出再导入  | ID、文字、绑定、图片与折点保留；撤销/重做可用        |

模型完成任务时做与本次变更相关的检查，不要求用户执行整套测试。开发回归应包含工具真实调用、原生鼠标拖动、持久化及混合手动/AI 编辑；模拟模型能验证工具链路，不能代表某个在线模型的理解准确率。
