# 小程序运营后台 · 需求清单（MVP）

日期：2026-10-04。状态说明：✅ 已实现并验证 / ⬜ 未做。

## 1. 基础
| 项 | 说明 | 状态 |
|---|---|---|
| 技术栈 | Node.js + Express + 内置 node:sqlite；React + TypeScript + Vite | ✅ |
| 中文界面 | 全部页面中文 | ✅ |
| 演示数据 | 合成用户/分类/商品/订单/公告，无真实支付、无第三方账号（仅开发/测试环境生成） | ✅ |
| 配置/数据库不入 Git | .env、data/*.db 均 gitignore | ✅ |

## 2. 功能需求
| 模块 | 需求 | 状态 |
|---|---|---|
| 登录/退出 | 管理员登录、退出；scrypt 密码哈希；DB 会话 + HttpOnly Cookie；登录限流 | ✅ |
| 安全会话 | 会话过期、Cookie SameSite=Lax、停用账号即刻失效 | ✅ |
| 仪表盘 | 用户/订单/GMV 总数与今日数、待发货数、最近订单、近7天趋势 | ✅ |
| 用户管理 | 按昵称/手机/openid 搜索、分页、启用/停用 | ✅ |
| 商品分类 | 分类增改删（有商品时禁止删）、排序、上下架 | ✅ |
| 商品 | 增改、分页搜索、上架/下架；价格/库存校验：拒绝负价格与负库存（新增与编辑均 400，0 元/0 库存合法） | ✅ |
| 订单 | 列表分页筛选、详情（含明细与收货信息）、合法状态流转、非法流转拒绝 | ✅ |
| 公告 | 标题/内容 CRUD、草稿/发布状态与筛选、发布时间 | ✅ |
| 角色权限 | admin 全权限；operator 可登录使用业务接口，不可管理管理员（列表/新建/停用均 403）、不可看审计日志 | ✅ |
| 操作审计 | 登录、启停、CRUD、订单流转均留痕，支持分页与关键词查询 | ✅ |
| 列表通用 | 所有列表支持分页与搜索；搜索无匹配返回 total=0 空数组，前端展示空状态 | ✅ |

## 3. API 集成测试（node:test，18 个用例全部通过）
- 未登录访问受保护接口 401；登录成功/失败；退出后会话失效；限流 429（只计失败，成功清零）
- operator 越权：管理员管理（列表/新建/停用）与审计日志均 403
- 用户/商品/订单/公告/管理员 CRUD、分页、搜索与空状态
- 商品负价格/负库存：新增与编辑均 400；分类不存在 400
- 订单非法流转 400、合法流转成功、终态不可再流转
- 公告草稿不出现在已发布列表；发布/撤回生效
- 审计留痕（含登录动作）验证、仪表盘统计结构验证

## 4. 安全与部署验收（2026-10-04 补充）
| 项 | 状态 |
|---|---|
| 默认仅监听 127.0.0.1；对外服务须显式设置 HOST=0.0.0.0 并配合 HTTPS 反向代理 | ✅ |
| 生产模式（NODE_ENV=production）必须显式 SECURE_COOKIE=1，否则进程启动即退出（exit 1） | ✅ |
| 生产模式不自动创建默认密码账号：未设 ADMIN_PASSWORD 时不创建任何账号与演示数据（默认密码登录 401）；已设密码时仅建账号、不生成合成演示数据 | ✅ |
| 登录 Cookie：HttpOnly + SameSite=Lax（Secure 随 SECURE_COOKIE） | ✅ |
| 移除未使用的 SESSION_SECRET 配置与全局屏蔽 warning 的代码 | ✅ |
| 密码 scrypt 哈希、DB 会话存储、登录限流、全量写操作审计留痕 | ✅ |

## 5. 验收命令
1. `npm run install:all`
2. `npm test`（18/18 通过）
3. `npm run typecheck`（tsc 无错误）与 `npm run build`（vite 构建成功）
4. 端到端 curl 验证：登录 Set-Cookie 含 HttpOnly/SameSite=Lax；带 Cookie 访问 200、无 Cookie 401；
   退出失效；生产模式安全检查符合第 4 节（详见 README「验证记录」）
