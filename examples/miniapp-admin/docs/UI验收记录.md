## 三、发现的问题与处理

| 问题 | 性质 | 处理 |
|---|---|---|
| 同舟 `client_change` 旧通道 `args` 只传字符串，无法传入 `saveConnector` 需要的对象参数（连续 7 次被参数校验拒绝） | 工具缺陷（非项目代码） | 用户修复参数兼容并新增 `argsJson` 后恢复；改用 `argsJson` 成功创建连接 |
| 原生 `window.confirm` 弹窗截图返回“未获取目标窗口图像”，只能盲按 ENTER/SPACE/盲点击，均无效 | 工具缺陷（非项目代码） | 用户修复后，对被阻挡窗口的截图可直接返回确认弹窗实际图像与独立 frameId；本轮对“发货”确认框按实际文字点击“确定”成功 |
| 电脑工具要求 frameId 一次性使用且截图约 2 分钟过期，连续动作常因“截图已过期”被拒 | 工具约束 | 严格执行“每张截图只执行一次动作，动作后必须重新截图”通过 |
| 公告“发布”点击后无二次确认（订单“发货”有 confirm） | 产品观察（非缺陷：需求未要求发布需确认） | 记录备查，未改动 |
| 数据库中留有更早外部测试遗留数据（“同舟验收分类”ID 7、“同舟验收商品”） | 测试数据 | 未操作、未删除，不影响验收结论 |

项目代码在本轮 UI 验收中未发现需要修复的缺陷；无项目代码改动。
