# 开发路线

## 0.1：统一入口与可追溯执行

首版功能见 README 与验证记录。任何未通过真实模型测试的模型组合不应标为“已认证兼容”。

## 0.2：Kimi / MiniMax 账号授权（已实现）

内置官方 CLI 的设备授权与 ACP 对话、模型目录、取消与工具审批；支持国内/国际账号，以及 API / 套餐 Key 预设。真实设备码发起和取消已验证，实际账号推理与 macOS 实机仍需验收。

## 后续：上下文与原生能力

- 同一 Codex 引擎/模型使用 thread/resume，跨引擎继续使用明确的交接分段。
- 版本化、带来源的任务摘要；区分约束、已完成操作、产物、未完成事项。
- MCP 与 Skills 可视化管理，显式确认外部命令和工具权限。
- 持久化供应商/模型能力矩阵与真实服务 opt-in 兼容性测试。
- UI 组件拆分、分页历史查询、长会话虚拟化、键盘可访问性完善。

## 后续：可控的多 Agent 写入协作

- 每个写入 Agent 独立 Git worktree，主任务接受补丁后整合。
- 任务依赖图、预算、并发与超时统一调度。
- 汇总模型自动整合结论，失败子任务可单独重跑。
- 避免将多个账号的凭据放在共享运行环境中。

## 后续

更多供应商正式 OAuth 插件、账号续期管理、显式可选的兼容网关、健康检查与副作用感知的故障恢复、经签名的自动更新、可选加密同步。不会以静默重试替代执行状态确认。
