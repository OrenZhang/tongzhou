## 0.5 工作台补齐

0.5.5：电脑控制和客户端管理改为独立能力卡片，解释用途并提供可复制会话示例；开关即时反馈、保存失败回滚，检测与启用状态分开，过期结果标为上次检测。检测中/失败/重试在原卡片显示，无任务时隐藏停止按钮。截图仅对原目标窗口做有限重试，不回退全屏；本机检测等待窗口首帧，返回失败阶段，运行中拒绝自检。删除会话弹窗增加正文留白、长标题换行和右侧危险操作按钮。

0.5.4：GitHub 仓库工具以保存/复用认证为主，自定义 OAuth 应用作为高级入口，修复授权/文档手动链接。会话使用 GFM、Lowlight、KaTeX 与 Mermaid：多语言代码高亮、复制、换行、公式、8 类已回归图表、源码与缩放预览。流式未闭合图表显示源码，完成后绘制；代码高亮在 Worker 内执行，图表动态加载。验证范围与渲染资源边界见验证记录。

0.5.3：移除独立项目/工作树管理页面及菜单，保留 Agent 的查询、创建、清理和代码托管操作。工作树会话按源项目分组，目录绑定不变，移除后历史仍可从原项目的归档列表访问。新增石墨/雾蓝/暖砂风格、独立明暗模式、三种本机字体组合、聊天字号、实时预览与恢复默认；统一中文排版和表单间距。154 项单元测试、外观与全页面 UI 回归通过，字体实测及边界见验证记录。

0.5.2：工作插件归入插件与工具；MCP/OAuth/代码托管认证继承系统代理。新增加密 OAuth 应用密钥、具体错误及重试状态、手动授权链接、Figma 桌面 MCP 入口。150 项单元测试通过。Figma 远程注册实测 HTTP 403，官方客户端资格尚未验收；GitHub 浏览器 OAuth 需自己的注册应用，已有账号/访问令牌可复用。

会话管理入口归到侧栏标题：悬停或键盘聚焦显示归档/恢复、删除图标，操作其他会话保持当前聊天和草稿。删除弹窗标明会话名称；运行中不能归档，删除时提示会停止任务。

0.5.1：飞书扫码集中到添加飞书机器人的接入方式选择；GitHub / GitLab 账号认证前置，项目显式绑定账号后可克隆、快进拉取和推送当前分支。新工作树继承源项目的账号绑定，也可单独调整。GitHub 仓库 MCP 保留在可选工作插件中，与模型订阅分别管理。143 项单元测试通过，真实私有仓库及平台账号权限待对应环境验证。

## 本轮修复的具体问题

- 无项目 / 只读被强制设置 plan，造成问候也触发规划：将权限控制移到原生私有配置与受控工具桥，使用普通模式。
- MiniMax 初次配置被提前写为空配置，导致账号误判：先让官方 CLI 初始化托管登录配置，再限制工具；实际匿名引擎回归已验证不会假成功。
- 工具目录 / Skill 正文每轮预加载和 ACP 每次冷启动：目录缓存、延迟连接、简介按需读取；同配置普通会话复用，停用仍逐次检查。
- 模型 / 提供商切换携带不适用的工具调用与图片：转换为带来源的公开历史；不移交私有签名和过期截图。
- 运行中补充结果不明却可能重发：已保存、排队、已送交、已应用、暂停分开；未知 steer 暂停而不自动重试。
- 连接器更换站点可能带上旧 Token：换 origin / 类型 / Client ID 清除旧凭据和刷新令牌。
- 并发写同一文件、审批期间版本变化：哈希与再次检查、进程内锁；批量修改先全量校验，并报告部分完成情况。
- Codex thread 恢复后累计 Token 被重复计入每轮：保存引擎段用量基线，只记录本轮增量；未上报用量显示未知。
- 删除会话遗留子任务和渠道绑定：父子一并阻断输入、取消收尾、清理私有工作目录和关联记录，关闭入站绑定。
- 打包后搜索工具路径依赖源码目录：按当前安装的系统包定位，并在仓库外的打包测试中运行真实搜索。
- 权限按钮只有静态状态：增加可重复执行的自有窗口测试，验证截图与 Unicode 输入并回显结果。
- Windows 项目命令反复排查环境：明确 PowerShell 5.1、输出 UTF-8、保留失败码，优先定位实际 Node 可执行文件；开发入口及安装包都验证命令有真实输出。
- 真实模型测评补齐 Git 未提交改动保护和先失败后成功的命令证据；追加 10 组普通聊天新会话 / 续聊测量。结果与首次失败记录见验证文档。
