# 当前实现基线 · 1.0.0

当前版本只维护一种数据格式和一条执行路径。模块边界见 [架构说明](ARCHITECTURE.md)，版本内容见 [发布说明](RELEASE_NOTES.md)。

| 模块       | 当前实现                                                                                    | 边界                                                     |
| ---------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 执行核心   | 所有模型经模型适配进入 Codex；统一工具执行、任务继续、压缩与线程恢复                        | 第三方登录、模型协议和服务容量遵循各平台实际能力         |
| 会话       | 普通聊天、项目会话、排队补充、停止后继续、分支与历史查询                                    | 中断后不自动重放工具或结果未知的输入                     |
| 本地存储   | SQLite 保存会话、配置、运行记录；.tzhou 保存文档、目录、原件、附件、作品与修订              | 不提供历史格式迁移；派生索引可重建                       |
| 工作区     | 文件树、侧边预览、Markdown / HTML 交互预览、文档聊天                                        | 用户项目路径保持由用户选择                               |
| 智库       | 内容库、作品、每日记忆、证据及修订记录                                                      | 后台整理使用统一自动任务规则；删除仍需确认               |
| 渠道       | 微信 ClawBot、飞书、企业微信、钉钉机器人及邮件 / Webhook 通知；共用发送、完成提醒和定时通知 | 客户端需保持运行与连接；扫码授权和平台账号权限由服务控制 |
| 插件与工具 | 动态发现、会话工具、客户端查询与配置修改、Skills、电脑控制                                  | 按会话执行模式及当前平台授权执行                         |
| 发布       | main / release 分支，Windows 与两种 macOS 架构打包，自动测试与安装包验证，校验文件          | 签名与公证依赖发行证书配置                               |

运行恢复、路径校验、数据完整性检查和第三方协议适配属于当前功能，不作为历史兼容逻辑删除。
