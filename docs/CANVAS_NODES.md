# 画布节点插件

画布存储布局和引用，工作流负责依赖顺序、缓存、取消和运行记录。节点插件负责自己的配置和执行。连接认证、MCP 工具和媒体原件继续由现有模块管理。

完整的 v1 接入契约、MCP 专用节点封装和自定义预览接口见 [节点插件体系](./CANVAS_PLUGINS.md)。内置可视化节点包括 Markdown、SVG、HTML、3D 全景和便利贴，可直接在“节点类型”中选择。现有节点的处理清单与 ComfyUI 兼容目标见 [节点盘点与统一方案](./CANVAS_NODE_PLAN.md)，首轮实现与边界见 [ComfyUI 接入](./COMFYUI.md)。

## 使用

- 右侧「画布聊天」与节点配置可同时打开，也可用工具栏分别收起。在画布内选择／新建会话和模型后，描述需要搭建或修改的流程，AI 会读取当前节点插件、配置和端口并用 `canvas_apply` 直接更新当前画布；后续对话继续调整原画布。只读会话仅提供建议，执行工作流需用户提出执行需求。
- 聊天保存双方消息和输入草稿，支持流式回复、停止、在面板内处理操作审批与问题；「完整会话」可查看完整工具调用过程。节点执行会话与画布聊天使用同一个会话选择。
- 发送前同步手动编辑；AI 更新后自动刷新。并发修改不同字段会合并，修改同一字段时暂停同步，选择使用最新版本或保留本地草稿后再继续。AI 修改也可通过画布撤销回退。

- 节点右下角可拖动改变尺寸，连线随尺寸更新；保存后重启仍保留。尺寸、位置变化不会使生成缓存失效。
- 点击图片预览，使用左右方向键、上一张／下一张和底部缩略图切换。右上角「媒体预览」重新打开上次浏览的位置。
- 资源节点可以添加自定义提示词，和引用内容一同传给下游。图片、视频节点可以直接填写提示词，也可连接提示词资源。
- 图片节点支持文生图、参考图生成、选择已有图片。视频节点支持文生视频、参考图、首帧、首尾帧；图片可从内容库或作品中选择，也可由相连节点提供。
- 比例、分辨率、时长、模型与额外参数属于每个节点的插件扩展配置。配置实际提交给所选工具，插件不支持的参数在调用前报错。首尾帧需要两张图及工具提供尾帧参数；仅支持公开 URL 的服务不能直接使用本地图片，不会自动上传。
- 保存位置位于节点配置顶部。默认保存到作品；指定内容库或本地目录时另外保存副本。已有图片也可用「保存到作品／内容库／本地目录」保存。

## 注册约定

`Canvases.plugins` 是注册表，复用 Cordis 生命周期。内置节点为文本、资源、Agent、图片、视频、音频、内容库保存和通用 MCP 工具节点。

每个节点插件声明：

- 稳定 ID、名称、渲染类型与正整数版本。
- 输入／输出类型，用于展示能力；执行依赖仍由画布连线决定。
- Zod 配置 schema；转换为 JSON Schema 后交给界面生成扩展配置。
- 执行器，接收冻结的画布运行、节点、上游输出、取消信号和现有任务入口。

```ts
ctx.effect(() =>
  ctx.tzCanvases.plugins.register({
    definition: {
      id: 'example.outline',
      name: '大纲整理',
      kind: 'plugin',
      version: 1,
      inputs: ['text'],
      outputs: ['text'],
    },
    schema: z.object({ prefix: z.string().default('大纲') }),
    execute: ({ node, inputs }) => ({
      text: node.config!.prefix + '\n' + inputs.map((value) => value.text).join('\n'),
      resources: [],
    }),
  }),
);
```

插件所在 Cordis 功能声明依赖 `tzCanvases`；返回的注销函数随功能卸载调用。节点运行记录保存插件 ID 和版本；卸载后保留画布数据，执行会明确报不可用。运行过程中插件版本变化会停止后续节点，需重新启动工作流。行为变化应更新版本，缓存会相应失效。

耗时、工具或模型操作通过执行上下文 `task(operation?)` 进入现有 TaskService，继承审批、取消、日志和作品采集。通用 MCP 工具节点复用已经启用的服务连接，并根据工具 schema 提供参数配置。连接密钥不写入节点。

图片、视频、音频复用同一执行与保存流程。新增供应商优先通过现有 MCP 插件注册工具，专有的 seed、style 等参数从工具 schema 进入「插件扩展参数」。画布主循环无需增加供应商判断。

会话通过 `canvas_list` 发现节点插件摘要，`canvas_read(pluginIds)` 按需读取配置 schema，再用 `canvas_apply` 和 `canvas_execute` 操作；不会将全部插件说明常驻到提示词里。

## 持久化

- `.tzhou/canvas/definitions/<id>.json`：布局、尺寸、节点插件 ID 与实例配置、资源引用。
- `.tzhou/canvas/runs/<id>.json`：运行快照、插件版本、进度、结果引用与异步媒体任务 ID。
- 作品、内容库保存媒体原件；运行中的任务、消息、审批沿用 SQLite。

## 导入、导出与模板

工具栏提供两种 JSON 导出，格式标记为 `tongzhou-canvas`、版本为 1：

- **工作流模板**保留节点、连线、分组、文本和非敏感生成配置；移除素材引用、账号连接和本机输出路径。导入后需要重新选择素材、模型/插件连接；不会自动执行。
- **项目**同时打包引用素材及最近一次运行的可用结果。结果恢复为独立资源/文本节点，运行历史与远端任务状态不迁移。素材按内容库原件重建引用，不依赖原电脑 ID。尚未下载的作品先下载原件，下载失败时不导出残缺项目。
- 导入始终创建新画布；素材总计上限 64 MB，JSON 文件上限 96 MB，画布仍限制为 200 节点、800 连线。导入校验格式版本、引用完整性、素材哈希与文件名；不会执行导入内容或覆盖现有画布。
- “保存为模板”存入内容库的“画布模板”目录，“模板库”可复用。提示词及普通文本可能包含用户主动填写的信息，分享前应检查导出内容。

## 交互与对话

- 小地图显示视口和选区，点击或拖动定位；保留原有适应全部、缩放和重置功能。
- Shift 拖动空白处框选，Shift 点击增减选择；Ctrl/Command+A 全选，Ctrl/Command+D 复制所选节点及内部连线。批量操作提供编组、取消编组、左对齐、顶对齐和水平分布。点击组内节点可整体移动，点击分组标题选中整组。
- 普通会话发送和画布助手发送前等待当前编辑器完成保存与关联，版本冲突会阻止发送，避免读取旧选区。执行中的节点仍使用原有冻结快照。
- 节点配置面板下方的“画布助手”复用执行会话、模型和权限，围绕当前选区自由提问。回答可以插入为文本/资源节点；替换为文本时更新所选节点提示词，媒体结果替换所选节点为资源节点。完整对话保留在会话中。
- 音频节点支持文本生成和已有音频；音色 ID、语速、模型及扩展参数按工具实际 schema 提交。MiniMax 套餐 `text_to_audio` 可直接选择；其他服务需要提供对应音频生成工具。音频可在节点内播放，并沿用作品、内容库、本地目录保存及逐项重试。

## 提示词库

内置原创分镜、人物、配音和风格模板。自定义提示词存为内容库文档（`contentType: canvas-prompt`），支持名称/标签检索、编辑、`{{变量名}}` 填写、插入文本节点或填入选中节点。变量未填完整或结果超过节点上限会明确提示；不会静默截断。URL 安装节点插件不在此功能范围内。
