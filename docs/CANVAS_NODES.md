# 画布节点插件

画布存储布局和引用，工作流负责依赖顺序、缓存、取消和运行记录。节点插件负责自己的配置和执行。连接认证、MCP 工具和媒体原件继续由现有模块管理。

## 使用

- 节点右下角可拖动改变尺寸，连线随尺寸更新；保存后重启仍保留。尺寸、位置变化不会使生成缓存失效。
- 点击图片预览，使用左右方向键、上一张／下一张和底部缩略图切换。右上角「图片预览」重新打开上次浏览的位置。
- 资源节点可以添加自定义提示词，和引用内容一同传给下游。图片、视频节点可以直接填写提示词，也可连接提示词资源。
- 图片节点支持文生图、参考图生成、选择已有图片。视频节点支持文生视频、参考图、首帧、首尾帧；图片可从内容库或作品中选择，也可由相连节点提供。
- 比例、分辨率、时长、模型与额外参数属于每个节点的插件扩展配置。配置实际提交给所选工具，插件不支持的参数在调用前报错。首尾帧需要两张图及工具提供尾帧参数；仅支持公开 URL 的服务不能直接使用本地图片，不会自动上传。
- 保存位置位于节点配置顶部。默认保存到作品；指定内容库或本地目录时另外保存副本。已有图片也可用「保存到作品／内容库／本地目录」保存。

## 注册约定

`Canvases.plugins` 是注册表，复用 Cordis 生命周期。内置节点为文本、资源、Agent、图片、视频、内容库保存和通用 MCP 工具节点。

每个节点插件声明：

- 稳定 ID、名称、渲染类型与正整数版本。
- 输入／输出类型，用于展示能力；执行依赖仍由画布连线决定。
- Zod 配置 schema；转换为 JSON Schema 后交给界面生成扩展配置。
- 执行器，接收冻结的画布运行、节点、上游输出、取消信号和现有任务入口。

```ts
ctx.effect(() =>
  ctx.tzCanvases.plugins.register({
    definition: {
      id: 'example.outline',
      name: '大纲整理',
      kind: 'plugin',
      version: 1,
      inputs: ['text'],
      outputs: ['text'],
    },
    schema: z.object({ prefix: z.string().default('大纲') }),
    execute: ({ node, inputs }) => ({
      text: node.config!.prefix + '\n' + inputs.map((value) => value.text).join('\n'),
      resources: [],
    }),
  }),
);
```

插件所在 Cordis 功能声明依赖 `tzCanvases`；返回的注销函数随功能卸载调用。节点运行记录保存插件 ID 和版本；卸载后保留画布数据，执行会明确报不可用。运行过程中插件版本变化会停止后续节点，需重新启动工作流。行为变化应更新版本，缓存会相应失效。

耗时、工具或模型操作通过执行上下文 `task(operation?)` 进入现有 TaskService，继承审批、取消、日志和作品采集。通用 MCP 工具节点复用已经启用的服务连接，并根据工具 schema 提供参数配置。连接密钥不写入节点。

图片、视频复用同一执行与保存流程。新增供应商优先通过现有 MCP 插件注册工具，专有的 seed、style 等参数从工具 schema 进入「插件扩展参数」。画布主循环无需增加供应商判断。

会话通过 `canvas_list` 发现节点插件摘要，`canvas_read(pluginIds)` 按需读取配置 schema，再用 `canvas_apply` 和 `canvas_execute` 操作；不会将全部插件说明常驻到提示词里。

## 持久化

- `.tzhou/canvas/definitions/<id>.json`：布局、尺寸、节点插件 ID 与实例配置、资源引用。
- `.tzhou/canvas/runs/<id>.json`：运行快照、插件版本、进度、结果引用与异步媒体任务 ID。
- 作品、内容库保存媒体原件；运行中的任务、消息、审批沿用 SQLite。
