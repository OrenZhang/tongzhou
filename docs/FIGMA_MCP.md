# Figma 连接与 MCP 权限

在 **插件 → 内置插件 → Figma** 中选择连接方式。普通用户无需创建 OAuth 应用或填写 Client ID / Secret。

## Figma 连接方式

| 连接方式 | 认证                                                | 能力与条件                                                                            |
| -------- | --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 远程 MCP | 使用 Figma 登录，由CoSail管理客户端注册与浏览器授权 | 需获得 Figma 的客户端接入资格；实际工具以连接检查返回的目录为准                       |
| 桌面 MCP | 无需在CoSail登录，连接 `http://127.0.0.1:3845/mcp`  | 在 Figma 桌面应用打开文件、进入 Dev Mode 并启用 MCP Server；不提供 `generate_diagram` |

截至 2026-10-12，CoSail已提交 **All Read and Write Tools** 接入申请，尚未获批。Figma 当前暂停新增远程 MCP 客户端，登录仍可能遇到客户端注册被拒绝（403）。提交申请或注册 REST OAuth 应用均不代表 MCP 接入已获准。

CoSail在远程模式通过 MCP 的授权发现和客户端注册流程处理认证，凭据在主进程加密保存；不会把开发者的 REST OAuth Client Secret 放入客户端或代码仓库。`tongzhou` 的 REST OAuth 应用目前为草稿，未用于 MCP 登录。获准后的注册方式应按 Figma 提供的接入要求配置。

官方资料：[远程 MCP 接入](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/) · [工具能力](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/)。

## MCP 权限如何检查

插件详情中的 **权限与连接校验** 分别展示：

- **账号授权范围**：仅显示令牌接口返回的 scope 名称；服务端未返回时显示无法确认，不把申请范围当作已授权范围。
- **连接检查**：执行认证、MCP 连接和工具目录发现，检查只读工具名称及声明冲突；不会通过创建、修改或删除数据来试探写权限。
- **工具分类**：展示CoSail认定的只读工具、写入或破坏性工具，以及未确认的工具。未确认工具按写操作处理。
- **Figma 图表生成**：检查目录是否包含 `generate_diagram`；桌面模式明确提示该能力需要远程 MCP。

工具目录只能说明服务提供了哪些调用入口。能否操作某个文件或项目仍取决于账号授权、资源权限、套餐和额度，服务端可在实际调用时拒绝。**连接检查通过不等于全部读写权限已验证。**

## 会话权限与只读校验

| 会话权限 | MCP 行为                                     |
| -------- | -------------------------------------------- |
| 只读     | 仅提供已确认的只读工具，其他工具不可调用     |
| 按需审批 | 工具操作遵循会话的审批规则                   |
| 完全开放 | 自动批准已启用工具，但不能扩大服务端授权范围 |

官方 GitHub、GitLab 和 Figma 端点可以识别工具的只读声明。自定义 MCP 的声明仅供参考，需要在高级设置显式填写已确认的只读工具名称。

保存已有已检查连接或再次检查连接时，会拒绝不存在的工具名，以及将明确的写入、破坏性工具设为只读的配置。Figma 的生成图表、创建文件、画布操作等官方写工具始终按写操作处理。未经检查的旧配置也不能在执行时覆盖明确的写操作声明；使用缓存目录的工具会在调用前核对服务器当前目录。

更换连接地址、认证配置或凭据后，先前的检查结果失效；退出登录后清除已授权范围。OAuth 令牌、刷新令牌和应用密钥不会出现在权限说明或工具目录中。

MCP 工具声明参考：[Tools / Tool annotations](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。
