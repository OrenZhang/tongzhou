# 内置网络配置

入口：**设置与优化 → 连接中心 → 网络配置**。安装内核，添加配置，然后在 **模型与订阅 → ChatGPT 连接 → 此连接的网络 → 内置网络配置** 中选择它。

同舟按需运行独立的 Mihomo 子进程。账号网页登录、设备授权、模型列表与聊天使用所选网络；不会设置系统代理、修改系统 DNS 或启动 TUN。节点故障会报错，不会自动回退系统网络。系统已有 VPN/TUN 仍可能影响底层路由。

## 配置与安装

- 支持含 `proxies` 数组的 Clash / Mihomo YAML、JSON；HTTPS 订阅须返回相同格式。支持 SS、VMess、VLESS、Trojan、Hysteria2、TUIC、HTTP、SOCKS5 的常用参数及 WS/gRPC/Reality 等传输选项。界面提供协议模板。
- 导入只提取节点；原文件的规则、代理组、DNS、TUN、监听器、脚本不执行。同舟将账号请求发送到当前选中的节点，不自动回退 DIRECT。
- 不支持仅含 `proxy-providers` 的配置、Base64/分享链接订阅、OpenVPN 文件或任意配置格式。含证书文件、插件路径等未支持的高级节点选项会明确拒绝。
- 每个网络配置有自己的内核进程、临时端口和当前节点。多个账号可复用一份配置。任务执行期间不能修改其网络、切换节点或停止内核；绑定账号的配置不能直接删除。
- 停止后，下次账号使用会自动启动。客户端退出会停止内核；独立监督进程在桌面主进程崩溃、IPC 断开时也终止内核；Windows 可能直接终止整个子进程组，未清理的临时目录在下次启动时回收。没有循环重试或隐式后台订阅更新。
- 订阅需手动更新，失败保留原配置。配置和订阅下载使用当前系统网络，不保证无可用网络时能下载。可先离线导入节点文件和内核压缩包，不依赖其他代理客户端。
- 固定内核版本 `v1.19.32`。首次在线安装从官方 GitHub Release 下载；也可选择指定版本的官方压缩包离线安装。Windows x64、macOS Intel / Apple Silicon 分别校验代码内固定的 SHA-256，校验失败不执行。

内置内核不提供节点或订阅，仍需用户自己的可用服务。首版账号网络绑定适用于 ChatGPT；其他模型、服务账号继续使用现有网络方式。

## 凭据边界

节点配置及订阅 URL 通过系统安全存储加密后存入本机数据库。界面及 Agent 查询仅返回名称、节点名和运行状态，不返回配置原文。导入和安装是手动操作；其他网络管理命令注册到客户端能力目录并遵循会话权限。

内核只监听回环地址，控制接口使用每次启动生成的随机密钥。启动配置写入专用临时目录（POSIX 目录 0700、文件 0600；Windows 继承用户数据目录的 ACL），加载完成立即删除；退出清理目录。内核输出不直接传回界面，避免错误中包含节点密码。项目命令不会继承账号代理环境变量。

## 上游与验证

Mihomo 以未经修改的独立程序运行，按需直接从上游下载，不随同舟源码或安装包分发二进制。其 GPL-3.0 许可证见 [MIHOMO-LICENSE.txt](MIHOMO-LICENSE.txt)，上游源码和对应版本见 <https://github.com/MetaCubeX/mihomo/tree/v1.19.32>。同舟主程序保持原许可证。

`npm run test:managed-network` 使用隔离用户目录、真实内核和本机合成出口验证导入、账号路由、设备授权请求、节点切换、按需重启、配置保密及退出清理；不是实际账号登录成功或付费模型推理测试。可用 `TONGZHOU_NETWORK_ARCHIVE` 指定离线压缩包，默认优先读取 `.test-data/` 下的对应压缩包，否则通过客户端安装。
