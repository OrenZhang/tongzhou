# 项目上下文面板

项目会话右上角的文件夹按钮打开面板。面板随当前项目与会话切换；普通聊天不显示项目文件。采用「文件 / 变更 / 说明」三个真正的页签，生成说明不再混在页签中。

## 文件

- 目录导航、上一级和根目录入口；按路径或文本内容搜索整个项目，遵循忽略规则。
- 内联只读预览，语法高亮、行号、横向滚动或自动换行；点击行号后引用到当前会话。
- 引用只追加到草稿，不覆盖已有文字、不自动发送。复制路径有明确反馈。
- 搜索结果直接定位行号。较长文件分批显示，读取上限仍为 500 KB，超限与二进制文件显示明确说明。

## 变更

- 未暂存范围包括未跟踪的新文件；已暂存范围读取索引，同一文件可分别出现在两个范围。
- 展示分支、文件状态、单文件增删计数及带新旧行号的彩色差异。
- 支持首次提交前的仓库、中文和带空格路径、重命名、删除文件、项目位于仓库子目录的情况。
- 点击行号后可把新/旧版本位置加入会话反馈；「请同舟审阅」生成当前范围的只读审阅请求，由用户发送。
- 普通非 Git 文件夹显示初始化入口，将要求放入会话；不因展开面板而运行写入操作。
- 展示整个项目工作目录的变更，不把用户已有的修改误标成 Agent 独有修改。

## 说明

- 查看根目录的 AGENTS.md / agent.md 与 README。
- 「生成基础说明」沿用现有独占创建逻辑，已有文件不覆盖，完成后直接打开说明。
- 「让同舟完善说明」把基于真实代码、命令和已有规则的维护要求加入当前会话草稿。

## 交互与边界

- 默认面板宽 360 px，可加宽；小窗口用侧面覆盖层，避免挤压聊天区。支持浅色/深色主题。
- 任务运行时定期刷新，任务状态切换与窗口重新获得焦点时刷新，关闭面板后停止读取。
- 所有异步结果绑定当前查询与文件，切换会话/项目后不会回显上一项目的数据。
- 本轮没有提供直接编辑文件、暂存/撤销、提交/推送、提交历史或上轮变更快照的按钮。这些操作仍由已有 Agent 文件/Git 能力执行并遵循会话权限；面板只负责定位、查看和反馈，不伪装成完整 IDE。
- 新增 `projectChanges`、`projectPatch`、`projectSearch`、`projectInstructions` 四项只读客户端注册，自动进入能力目录供 Agent 使用。

## 验证

- `tests/modules/projects/project-context.test.ts`：真实临时 Git 仓库，验证新文件、索引与工作区分离、重命名/删除、子目录边界、忽略规则、二进制与行号解析。
- `npm run test:project-context`：隔离 Electron 配置与示例项目，操作文件/搜索/差异/引用/说明初始化，覆盖深色与窄屏。不会使用真实用户项目或模型账号。

设计参考：[Codex 官方本地变更审阅说明](https://learn.chatgpt.com/docs/code-review?surface=app)。同舟实现文件定位和会话反馈闭环，不声称覆盖该产品全部审阅功能。
