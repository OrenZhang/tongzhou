# ComfyUI 工作流

CoSail 使用现有画布、插件连接、任务审批和作品库对接 ComfyUI。ComfyUI 服务负责模型加载和内部生成图执行；不需要额外安装 MCP，也不会在导入 JSON 时安装 Python 节点或模型。

## 连接服务

1. 在「插件 → 内置插件 → ComfyUI」填写服务地址，例如 `http://127.0.0.1:8188`；远程连接使用 HTTPS。
2. 如果服务前面配置了 Bearer 认证，填写访问令牌；凭据沿用插件连接的加密存储，不写入画布。
3. 启用服务，点击「保存并检查」。检查读取节点目录，不提交生成任务。

ComfyUI 服务与 MCP 连接分开识别，但复用同一插件配置和认证存储；不会向 ComfyUI 的地址发送 MCP 初始化请求。

## 两种使用方式

### 导入并展开节点

在工作流画布点击「导入」，选择 ComfyUI 的 JSON。支持 API 格式及普通 UI 0.4 / 1.0 格式。没有服务时也可以先导入、查看、保存原件。

选中导入节点，在配置面板选择服务，点击「检查并应用服务」。同一导入图会使用该服务的真实节点定义解析控件和端口。未完成的控件映射会显示原因；不能解释的节点不会被删除或伪装成普通节点。标量参数可以编辑或连接上游；连线值优先于本地参数。ComfyUI 标量输入只接受一个上游，多个提示词先用文本模板合并。

- 文字节点可连接到 `in:text` 等提示词参数。
- 资源图片可连接到 LoadImage 的 `in:image`；执行时上传原件，不传本机路径。
- `out:0` 等是 ComfyUI 内部端口，`comfyui:IMAGE`／`MODEL`／`LATENT` 等值留在同一个服务执行单元内。
- 输出节点的 `files` 端口是已下载保存的文件，可接 Agent、保存到内容库等普通节点。

点击「运行整个流程」；也可以选择包含输出节点的依赖分支运行。同一导入图、同一服务的内部节点按一个单元提交。若本地处理穿插进内部图而形成无法编译的执行边界，会说明原因，不重复运行整张图来绕过。

### 使用一个工作流 API 节点

在节点库添加「ComfyUI 工作流 API」，选择服务并粘贴 **API 格式** JSON。适合把已有生成流程作为较大工作流中的一步。

输入绑定将外层端口对应到流程内的参数，例如：

```json
[
  { "port": "prompt", "nodeId": "6", "field": "text" },
  { "port": "reference", "nodeId": "10", "field": "image" }
]
```

`nodeId`、`field` 必须使用自己的流程 ID 和参数名。没有上游时使用流程原有参数；有上游但未绑定时明确报错。输出 `result` 是生成文件。需要归入内容库时，连接已有保存节点。

API 节点与展开的导入图共用参数检查、上传、提交、查询和素材回收，不维护第二套执行器。

## 执行与恢复

- 沿用会话权限。审批通过前不上传素材、不提交生成。
- 连接允许无请求头的 WebSocket 时显示节点进度；使用请求头认证或 WS 不可用时回退 HTTP 查询。未观测到的内部节点仅表示图已结束，不声称它实际重新计算过。
- 保存远端 `prompt_id`、服务身份、输入指纹和实际提交参数。普通 UI 的固定／随机／递增／递减种子控制被记录；重新查询沿用原任务，不重新抽种子。
- 断线、超时或客户端重启后，选中对应历史运行，使用「继续查询 ComfyUI 任务」。服务或输入发生变化时拒绝按原任务恢复。
- 「停止」中止本地跟踪；不调用共享服务的全局 interrupt。远端计算可能继续，可以之后重新查询。
- 提交结果未知且没有远端任务 ID 时，不会自动重发；先检查 ComfyUI 服务端队列与历史。
- 成功输出取回为真实作品原件，复用现有预览和内容库。已生成结果不会因为某次查询失败而被标成重新生成成功。

## 保存与兼容范围

- 工作流定义和运行仍保存在 `.tzhou/canvas/definitions`、`runs`；导入原件单独保存在 `imports`，带哈希校验。
- CoSail 项目／模板包携带导入原件；有 ComfyUI 原件的包使用版本 2，旧的版本 1 仍可导入。导出会移除服务绑定和已识别的认证字段，接收端重新配置服务。
- 「导出 ComfyUI API」导出当前纯 ComfyUI 图的参数、标题与连线修改；它不包含原 UI 布局。混合本地节点的完整工作流请使用 CoSail 项目导出。
- 当前限制：导入 JSON 4 MB、200 节点／800 边；单节点 API JSON 24,000 字符；每个文件 25 MB、单次最多取回 32 个文件。现有画布每次最多 50 个执行节点的限制保留。
- 已安装自定义节点可按真实目录发现；依赖特殊前端控件、旁路／禁用、子图、无法推导的动态端口等情形会保留原件并阻止相关执行。此时优先在 ComfyUI 整理后导出 API 格式。

## 验证

`tests/modules/canvas/comfyui.test.ts` 使用隔离 HTTP 服务和真实 TaskService 验证导入、控件映射、输入绑定、文件保存、审批拒绝、取消恢复和不重复提交。`npm run test:comfyui` 使用隔离 Electron profile 验证界面操作；这些测试使用模拟输出，不代表真实模型出图验证。

当前没有可用的真实 ComfyUI 实例，真实模型、GPU、自定义节点组合及视频生成仍需在目标服务验收。

官方参考：[工作流格式](https://docs.comfy.org/specs/workflow_json)、[节点定义](https://docs.comfy.org/specs/nodedef_json)、[服务接口](https://docs.comfy.org/development/comfyui-server/comms_routes)。
