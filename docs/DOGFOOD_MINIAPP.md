# 小程序后台：同舟真实开发验收

日期：2026-10-04。起始版本：0.5.6（8976c71）。

## 方法与范围

在 Windows 桌面创建“小程序后台”，通过同舟实际窗口导入项目、选择已有 Kimi 账号连接，并提交完整开发需求。项目代码由同舟会话生成。用户明确要求：项目的编码、启动、验证、修复均由同舟执行；外部操作者只操作同舟、记录问题和修复客户端。此前外部运行的 API/构建及浏览器检查不计为同舟自主验收。仅使用合成业务数据。

项目目标：React/TypeScript 管理界面、真实持久化 API、登录和角色权限、仪表盘、用户、分类/商品、订单流转、公告、审计、自动测试、运行文档和 GitHub 仓库。
