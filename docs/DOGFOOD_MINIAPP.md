# 小程序后台：同舟真实开发验收

日期：2026-10-04。起始版本：0.5.6（8976c71）。

## 方法与范围

在 Windows 桌面创建“小程序后台”，通过同舟实际窗口导入项目、选择已有 Kimi 账号连接，并提交完整开发需求。项目代码由同舟会话生成。用户明确要求：项目的编码、启动、验证、修复均由同舟执行；外部操作者只操作同舟、记录问题和修复客户端。此前外部运行的 API/构建及浏览器检查不计为同舟自主验收。仅使用合成业务数据。

项目目标：React/TypeScript 管理界面、真实持久化 API、登录和角色权限、仪表盘、用户、分类/商品、订单流转、公告、审计、自动测试、运行文档和 GitHub 仓库。

## 问题记录

每条问题记录触发步骤、预期/实际、根因、修复和回归证据。无法完成的外部服务验证与客户端缺陷分别记录，不把模拟测试描述为真实服务验证。

| 编号 | 实测问题 / 根因 | 修复及回归 |
| --- | --- | --- |
| DF-01 高 | Kimi 两轮开发都在连续写文件后报告全部 MCP 通道关闭。ToolScope 把 maxSteps=32 当作工具总次数；超限抛异常，HTTP 400 又被代理翻译为通道关闭。 | 移除工具层重复计数；桥接返回真实 MCP isError。默认直接 API 模型轮次为 0（不限）；自定义 Agent 仍可设轮次。80 次桥接调用及错误后恢复、35 次模型响应回归通过。 |
| DF-02 中 | 文件已写入，右侧仍显示空目录；只在运行 ID 变化时刷新。 | 运行期间每 2.5 秒刷新当前文件/Git 面板，丢弃旧请求，防重叠。真实 Electron 中运行未结束时创建文件可见。 |
| DF-03 中 | 长内容突然增长后不再跟随，用户误以为停住；渲染后才判断距底部距离。 | 记录阅读位置，观察内容尺寸，向上浏览不抢滚动；提供“回到最新”。大段流式输出、历史阅读、恢复跟随已回归。 |
| DF-04 中 | 快速流式片段后暂停时尾部不显示，直到下一片段/结束；节流缺少尾部刷新。 | 增加 60ms 内尾部刷新，沿用同一消息。真实 SSE 停顿场景回归通过。 |
| DF-05 中 | Kimi 运行中补充显示等待安全点，实际生成独立 run。 | ACP 在当前 prompt 结束后消费补充，保持同一 run；项目/普通聊天两类单元回归通过。 |
| DF-06 外部阻塞 | GitHub 新建仓库网页被用户保存的浏览器网站权限拒绝。 | 未绕过；已请求用户提供空仓库地址。已连接 GitHub 接口可用于既有仓库推送。 |
| DF-07 高 | 不设手动历史预算时，完整历史持续增长直到服务端拒绝。 | 自动按启发式字符阈值整理较早记录，保留初始目标、当前请求和完整工具交换；原始历史保留，可用 read_history 分段读取。直连接口明确上下文溢出且未输出时缩小历史后重试；已输出或其他错误不重试。不是语义摘要，也不声称无限模型容量。 |
| DF-08 中 | 电脑操作只显示系统指针，难以分辨 Agent 的动作。 | 新增紫色指针、脉冲光圈及动作标签；透明点击穿透、不抢焦点，截图前隐藏，结束/失败/取消清理。Windows 真实截图、中文输入、快捷键和点击回归通过。macOS 尚未实机验证。 |
| DF-09 中 | 独立浏览器强制 HTTPS，无法打开本机开发页面。 | 仅浏览器类连接允许 localhost、127.0.0.1、[::1] 的无凭据 HTTP；认证服务地址继续要求 HTTPS。边界测试通过。 |
| DF-10 高 | Kimi 将 client_change 的动态 args 对象序列化成字符串，重复创建连接失败。 | 增加显式 argsJson 通道，解码完整参数数组后沿用原有凭据检查、权限和类型校验；禁止同时提交两种参数。回归验证对象/布尔值及非法输入。 |
| DF-11 中（待改进） | 同舟自主 UI 验收报告原生 select 下拉弹层未出现在窗口截图内，改用方向键/首字母选择。 | 窗口截图对子弹层的覆盖需进一步改进；本轮保留键盘操作作为可用路径，不把它描述为已修复。 |
| DF-12 低 | Kimi 多次在点击后复用同一 frameId 输入，错误笼统显示“截图过期”。 | 补充工具说明与错误文案：截图仅可执行一次动作；使用后需重新截图。该限制仍保留。 |

## 运行记录

- 导入目录后自动创建项目会话；选择 Kimi 订阅。现有全局权限为完全开放，本轮没有变更权限设置。
- 首轮需求要求生成 agent.md、实现真实功能、运行 API 测试/类型检查/构建并修复。界面已出现实际环境检查工具调用，检测到 Node 22.19.0 和内置 SQLite。
- 同舟自行发现并修复小程序项目 Windows 测试目录路径、登录限流误计成功登录等问题；后端 18 项测试通过，前端继续生成。
- 本轮桌面解锁后的 test:desktop、test:capabilities 通过，剪贴板验证恢复正常。修改后的单元测试 168 项通过；追加原生补充修复后针对 native/runtime/extensions 的测试通过（最终全量数另行更新）。
- 最新全量单元测试：22 个文件、176 项通过。Windows 构建与类型检查通过；彩色指针、原生弹窗加入后真实电脑工具回归通过。
- 同舟经 argsJson 自己创建并打开本地测试浏览器，随后使用真实截图/点击/输入完成登录、仪表盘、用户搜索空状态、清除恢复、分类新增/编辑/上下架。商品、公告和订单继续验收中；最终结果以项目内由同舟生成的 UI 验收记录为准。
