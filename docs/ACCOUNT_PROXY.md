# ChatGPT 账号独立代理

入口：模型与订阅 → 管理 ChatGPT 连接 → 此 ChatGPT 连接的网络。授权弹窗也可通过「配置账号网络」返回此处。

- 默认网络：保持既有行为，网页登录使用系统浏览器。
- 独立代理：填写代理软件的 HTTP 或混合端口，例如 `http://127.0.0.1:7890`，然后保存。支持 HTTP / HTTPS 代理，不支持含用户名密码的代理 URL、PAC 或 SOCKS 专用端口。
- 不使用代理：关闭该账号的应用层代理。操作系统 VPN / TUN 全局路由仍由操作系统决定。

配置按连接保存。新设置应用于账号授权、设备码请求、令牌刷新、模型列表与后续聊天引擎；不会修改主进程环境、系统代理、其他模型连接或服务浏览器的网络。正在运行的账号不能修改网络，避免中断任务；其他账号任务不因此停止。保存不退出已登录的账号。

独立代理和直连模式下，网页登录使用单独的沙箱浏览器窗口，不共享系统浏览器 Cookie，不向模型暴露网页密码。登录回调的 localhost / 127.0.0.1 / ::1 保持直连。取消授权、退出账号或修改网络时关闭该授权窗口。特定身份提供商可能限制内嵌浏览器，可改用设备码流程。

「保存并测试账号网络」访问 OpenAI 公开的授权服务发现地址，显示可达状态与耗时，不调用模型，也不代表已完成授权或具备模型权益。代理软件需保持运行；错误的端口不会静默退回直连。

实现使用账户引擎专属进程环境和 Electron 独立 Session。传给 Codex 的代理环境不会通过其 shell 环境策略继续传入项目终端命令。客户端能力目录自动暴露查询测试接口，并保留网络配置的输入参数结构。

验证：单元测试覆盖 URL 校验、环境隔离、账号引擎参数和能力目录；`npm run test:account-proxy` 使用本地模拟代理与真实内置 Codex，验证设备授权请求进入指定代理、浏览器独立路由、本机回调直连和配置回显。模拟代理主动返回失败，不使用真实账号或发起付费推理；真人登录与模型推理需以实际网络和账号测试为准。

参考：[Electron 独立 Session 与代理配置](https://www.electronjs.org/docs/latest/api/session)、[Codex shell 环境配置](https://learn.chatgpt.com/docs/config-file/config-reference)。

内置网络配置现已单独实现：支持由同舟管理内核、导入节点并绑定账号，见 [内置网络配置](MANAGED_NETWORK.md)。原有独立代理地址功能仍可继续使用。
