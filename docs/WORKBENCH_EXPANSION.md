## 实施顺序和验收

1. 外观与输入：统一标志；主题三选一且重启保存，系统模式响应系统变化；明暗主题下保持正文、禁用状态和焦点可辨认。多项收件人、允许用户、MCP 参数使用可添加/删除的输入；草稿按会话保存。
2. 通知：保留飞书/企微/钉钉 Webhook，加入 SMTP 邮件（TLS/STARTTLS、收件人、加密密码）。通知目标与规则分别管理；规则支持所有/指定会话、完成/失败/中断/待批准/轮次结束、一次性、执行时长/模型/项目条件。会话内可开启本轮/下一轮提醒。事件与发送结果留记录，未知结果不自动重发。
3. 机器人：单独的数据模型、凭据和页面。飞书长连接、企业微信智能机器人 WebSocket、钉钉 Stream；保存后按需连接，展示真实状态。命令包括帮助、会话列表、进度、选择会话、创建/继续任务、停止；默认只查看，执行须允许用户和会话范围。远程消息去重、跨发送人绑定隔离，默认不返回聊天正文。
4. 工作插件：在服务区域提供官方 MCP 目录（GitHub、Figma 与常用办公服务），搜索、配置、启停、工具发现。Bearer/请求头与 OAuth 认证加密保存；浏览器 Cookie 与 MCP 凭据分离。OAuth 使用 SDK 发现、PKCE、state、loopback 回调、刷新/注销；无注册信息时显示准确的配置需求。
5. 内置 Git 工作目录能力（0.5.3 调整）：移除独立管理入口和自定义表单，查询、创建、清理由 Agent 的工具桥执行。创建工作树不复制未提交改动，不执行仓库设置脚本；会话绑定真实路径，在侧栏归入源项目。主工作树/外部工作树只查看，删除同舟工作树前检查未跟踪/忽略文件、未推送提交、活动会话、子模块和路径归属，不使用强制删除。
6. 测试：通知过滤/去重/SMTP 失败与未知结果、机器人身份/指令/消息重复/权限、OAuth callback/state/凭据隔离、真实 Git 临时仓库、主题切换/多值输入/会话草稿与全功能桌面回归。真实第三方授权与发信须有实际账号；协议夹具成功不标为真人服务验收。

## 当前实现

上述六组功能已进入开发预览。0.5.3 中工作树转为 Agent 内部能力，工作插件位于“插件与工具”；保留连接中心“机器人”、设置页“外观与字体”及会话通知铃铛。外观包含三套风格、独立明暗模式、本机字体选择与聊天字号。最新测试结论与真实服务待验项见 [验证记录](VALIDATION.md)。

## 模块边界与权限

- “通知”是出站目标及触发规则；“机器人”是入站控制会话；二者共享实际会话和轮次状态，不共享任意消息执行入口。
- “服务与插件”保存账号与 MCP 授权、提供办公工具；“独立浏览器”保存网页登录态，不把 Cookie 当成 API 凭据。
- 会话中的客户端操作复用已验证的业务接口。凭据编辑和远程控制授权只能从设置界面完成；不会通过提示词自动扩大权限。
- 不自动启用所有插件，不恢复内置规划角色，不把只读检查、模拟协议测试或本机 Windows 验证描述为全平台真人验收。
