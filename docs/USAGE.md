# CoSail 使用指南

[返回中文介绍](../README.md) · [English](../README.en.md)

## 快速开始

准备 Node.js **22.19+（22 LTS）**、npm 和 Git，然后运行：

```bash
git clone https://github.com/OrenZhang/tongzhou.git
cd tongzhou
npm ci
npm run dev
```

启动后：

1. 在 **设置 → 模型** 中添加模型连接或登录已适配的订阅账号，在会话中选择模型开始聊天。
2. 在 **智库** 中导入资料或新建笔记，按需让 Agent 整理、检索和沉淀知识。
3. 在 **设置 → 连接中心** 中配置服务账号、通知和机器人，选择允许访问的用户与会话范围。
4. 在 **插件** 中启用所需的 MCP、Skills、浏览器或电脑控制能力；需要开发代码时打开项目。

同一 API 网关可在模型连接的 **高级：按模型设置接口协议** 中为个别模型选择 Chat Completions、Responses、Anthropic 或 Gemini，其余模型继承连接协议。按网关实际支持情况配置；保存后从下一轮生效，请求失败不会自动切换协议重发。**分项连接检测** 可选择具体模型验证推理与工具参数。API Key 保持加密保存，在本机界面点击查看／隐藏或复制；留空保存会保留已有密钥。

在 **设置 → 模型 → 编辑连接 → 高级：模型思考** 中，可配置思考强度 `low / medium / high / xhigh / max`。官方账号按模型目录校验支持的档位；API 连接以服务实际支持为准，未指定时保持 `medium` 默认。配置保存后从下一轮生效，实际档位记录在 Run 中。内置 Codex App Server 固定为 `0.162.1`，负责工具循环、原生上下文压缩与线程恢复；有原生计划事件时在本轮处理过程展示步骤。

在同一个编辑连接窗口的 **自动模型路由** 中配置模型池，可引用其他连接的模型，为通用、编程、文档、图片场景及问答、规划、执行、检查、总结阶段指定模型与思考强度。保留一项“通用默认 / 所有阶段”作为默认；更具体的规则优先，同优先级按列表顺序。会话选择 **自动路由** 后，每轮开始使用本地规则识别场景和阶段，也可手动指定阶段；简短的“继续”沿用上一轮场景和阶段。已停用、已移除或未配置密钥的 API 连接会跳过；图片上下文只使用明确勾选支持图片的候选。官方账号仍需完成登录，服务端账号权益以实际调用为准。工具循环、追问补充和完成检查保持本轮模型与思考强度，下轮重新选择。选择具体模型即可固定模型，配置模型池不会改变原有固定模型请求。此路由不额外调用分类模型、不插入任务提示词，也不在服务报错或工具执行后自动换模型重发。

任务支持结构化追问，可选择选项或填写补充内容；完全开放权限不会代替你回答。官方账号及 GPT-6 原生 Responses 连接支持原生子 Agent，可在处理过程查看状态、停止和继续。执行过程显示核心报告的模型、思考强度、压缩次数及父子任务用量，进度说明与最终答复分别展示。

macOS 的CoSail密钥改为本地加密保存，不再调用系统钥匙串。旧版钥匙串密文会保留，但不会自动解锁或迁移；标为需要更新的连接请重新填写 Token，OAuth 插件请重新登录。重新保存后，日常读取密钥无需系统密码。加密密钥位于应用数据目录的 `local-secret.key`，随手动复制数据目录一同保留；应用导出的备份仍不包含认证凭据。

插件列表使用紧凑卡片，仅展示图标、名称、类型和启用开关。点击名称进入统一详情页，按插件类型展示连接与认证、本机账号、依赖安装、工具列表或技能指令；返回列表保留搜索与类型筛选。渠道属于始终可用的内置应用，其具体账号开关在渠道管理中操作。

**漫剧制作** 在内置插件中提供一个统一技能入口，整合 AI-drwa 的五套模板、导演/场记规范和结构检查，覆盖小说改编、人物/道具/场景资产、分镜、图像/视频/配音提示词及整集交付。详细资料按阶段读取，长模板支持按行读取；不会自动调用尚未配置的媒体服务。检查脚本使用本机 Python 3.9+，可指定项目根目录及剧本、分镜、交付阶段，结构通过与实际媒体审核分别记录。该技能包保留上游 **CC BY-NC 4.0** 许可，见 [来源与适配](../skills/manju-production/references/sources.md)。

时间和系统信息查询已并入核心工具，按需调用，不再以“系统环境”MCP 插件展示或启动额外进程。已有配置会在启动时自动迁移。

漫剧作品与人物、道具、场景设定优先复用智库内容库，使用现有目录、文档版本和来源关联维护采用记录。内容库可预览 3 MB 内的 PNG/JPEG/WebP 原件，AI 通过 `content_read` 的 `includeImage` 按需读取；文档菜单支持下载完整原件，普通正文导出行为保持不变。音视频及其他格式只保存原件与记录，媒体审核需实际可用的工具。

“网页搜索与读取 · 内置”在新配置中默认开启，已有用户手动设置保持不变。`web_search` 通过必应公开 RSS 搜索返回关键词结果，无需模型账号或 API Key；`fetch_page` 读取指定网址正文。搜索请求允许必应国内站点跳转，遇到网络错误、验证页或响应格式变化时会明确报错，不会当作没有结果。该公开搜索入口不提供商业 API 的可用性保证。

在 **插件 → 内置插件 → MCP** 中配置 MiniMax 多媒体、MiniMax 搜索与图片理解，以及 Kimi 搜索与网页读取。默认关闭，点击插件名称进入详情，优先选择 **使用CoSail套餐账号**，绑定模型页面中已登录并启用的对应账号，不必复制 API Key 或安装 Python。调用时读取最新授权，模型与插件共享令牌刷新；账号停用、移除或退出后不可继续调用。凭据仅留在主进程，固定发往官方套餐接口，不传给 MCP 子进程。

- **MiniMax 套餐模式**：搜索与图片理解提供联网搜索、HTTPS 图片理解；多媒体提供图片生成、语音合成、音色查询、视频生成和查询，返回媒体 URL。适配已锁定的 `@minimax-ai/code` 0.4.12 套餐接口。声音克隆、声音设计和本机播放仍使用 API Key 模式；工具能力、额度以服务端账号套餐为准。
- **MiniMax API Key 模式**：使用[官方多媒体 MCP](https://github.com/MiniMax-AI/MiniMax-MCP) `minimax-mcp==0.0.19` 和[官方 Coding Plan MCP](https://github.com/MiniMax-AI/MiniMax-Coding-Plan-MCP) `minimax-coding-plan-mcp==0.0.5`。仅此模式需安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，在详情中安装／修复依赖或指定 uvx 路径。密钥加密保存，区域需与密钥一致；切换套餐模式会保留已有密钥供以后切回使用。
- **Kimi 搜索与网页读取**：CoSail适配 [Kimi Code 的服务接口](https://www.kimi.com/en/help/kimi-code/cli-config-files)，可复用CoSail Kimi 登录，也可单独配置 Kimi Code API Key，无需 Python。套餐模式只允许匹配的官方服务端点与授权引用。

保存并检查连接验证凭据读取和工具目录，不调用付费生成接口，也不代表服务端已验证套餐权限或额度。生成请求失败不会自动重发，避免重复消耗额度。

Windows 上点击窗口右上角的关闭按钮会隐藏到系统托盘，后台会话与机器人连接继续运行。点击托盘中的CoSail图标，或右键选择 **打开CoSail**，即可恢复窗口；右键选择 **退出CoSail** 才会完全退出客户端。

在 Windows 和 macOS 的 **设置 → 电源与睡眠** 中，可开启 **接通电源时保持唤醒**：阻止空闲自动睡眠，同时允许屏幕熄灭。仅在接通电源时生效，拔电后暂停，退出CoSail后释放。另可开启 **接通电源时合盖不睡眠**，关闭功能或退出后恢复原设置：Windows 只临时修改当前电源计划的交流电合盖动作，不更改电池策略；macOS 无需外接显示器，但每次启动CoSail后需重新开启合盖模式并通过系统管理员授权，此模式会临时禁用系统睡眠（包括手动睡眠），辅助进程监测拔电与应用退出后恢复。异常中断的恢复记录会保留，失败时设置页显示重试入口。合盖运行时请保持散热通畅。

GitHub 和 GitLab 的认证统一在 **插件 → 内置插件** 管理，选择 **Token 配置** 或 **OAuth2 授权**。连接中心只管理独立浏览器登录、渠道通知、机器人和网络，不再提供 GitHub/GitLab 账号配置入口；已有账号数据保留，可在插件的 Token 来源中复用。

- **GitHub**：Token 和 OAuth2 均使用官方远程 MCP。OAuth2 点击 **使用 GitHub 登录**，在 GitHub 官方页面输入界面显示的验证码并授权；普通用户无需配置 Client ID/Client Secret。应用身份由CoSail维护者在构建时配置，支持授权保存、令牌刷新和退出；维护者配置见 [GitHub 登录](GITHUB_LOGIN.md)。可点击 **检测本地账号** 识别 Git 凭据或 GitHub CLI 当前登录，再点击 **使用并启用**。CoSail重新验证身份及 MCP 连接后加密保存，检测结果仅展示账号和来源；手动 Token 的 **保存并检查** 同样验证账号和工具连接。
- **GitLab**：填写 GitLab.com 或自建实例 HTTPS 根地址。Token 模式使用官方 REST API，无需开启 MCP；**保存并检查** 验证身份与项目 API，读取通常需要 `read_api`，写操作需要 `api`，并受项目权限限制。会话通过 `gitlab_api_read` / `gitlab_api_write` 调用实例上的项目、仓库、Issue、Merge Request 和 CI/CD API，写操作遵循会话权限。OAuth2 点击 **使用 GitLab 登录**，在所填实例的官方页面登录授权，授权加密保存在本机，普通用户无需填写 Client ID / Client Secret。此方式通过官方 MCP 自动注册 OAuth 应用，要求实例支持并开启 MCP 和应用自动注册；管理员关闭自动注册或实例不支持时，可改用 Token 配置。插件卡片与 Token 配置弹窗均支持本地 Git / glab 检测，**使用并配置** 保存 Token 账号；切换地址清除旧检测结果，不将普通 Token 当成 MCP OAuth 授权。

认证依据：[GitHub 官方 MCP 接入](https://github.com/github/github-mcp-server/blob/main/docs/host-integration.md) · [GitLab REST API 认证](https://docs.gitlab.com/api/rest/authentication/) · [GitLab 官方 MCP](https://docs.gitlab.com/user/model_context_protocol/mcp_server/)。仅保存凭据会显示待检查，通过连接检查后才显示已验证。

**Figma** 支持远程浏览器授权和桌面 MCP，应用配置由CoSail管理，用户无需填写 Client ID / Secret。CoSail已申请远程 MCP 全部读写工具接入，尚未获批；当前可连接 Figma 桌面 MCP 读取设计，FigJam 图表生成需要远程服务。插件详情提供授权范围、工具读写分类及只读配置校验；连接检查不会执行写操作，也不代表拥有所有文件或项目的读写权限。详见 [Figma 连接与 MCP 权限](FIGMA_MCP.md)。

智库的使用流程、来源核对与本地数据说明见 [本地智库与每日记忆](KNOWLEDGE-CENTER.md)。

**智库 → 创作** 自动索引已保存的画布和白板，支持搜索、类型筛选、重命名、删除和重新打开；**内容库** 位于智库首个标签。**作品** 按日期分组，可点击日期折叠或展开，折叠状态会保留。

## 通用画布与工作流

在导航中打开 **创作**，从中央入口选择 **工作流画布** 或 **白板**，也可直接打开最近的创作。工作流节点库默认收起为图标，展开后可拖入节点；点击节点即可编辑，配置浮窗与 AI 对话独立显示。节点插件支持文本、资源、Agent 处理、图片生成、视频生成、内容库保存及通用 MCP 工具调用；资源选择器支持内容库、会话作品、会话消息与项目文件，图片原件按需预览，不复制另一套素材库。

- **资料引用**为虚线，仅提供节点输入；**执行依赖**为实线，决定上游先后顺序，保存时拒绝循环依赖。
- 可运行全部节点，或运行所选节点及其依赖。首版按依赖顺序串行执行，每次最多 50 个节点。
- 启动时固定画布版本；编辑用于后续运行。失败后可重试，勾选复用时，输入、连接配置、Agent、工具和权限未变化的已完成结果可复用。停止保留已完成产物；应用重启不会自动重放中断任务。
- 执行节点复用现有 TaskService 和会话权限，Agent 节点沿用模型连接的思考设置；审批、追问在对应节点的执行会话中处理。图片生成需要已启用且可用的生图插件，只有真实图片产物才算成功，不把提示词或文字说明当成图片。
- 保存节点将正文及生成的本地作品原件交给现有内容库保存，保留来源引用。画布定义以 JSON 原子写入 `.tzhou/canvas/definitions/`，运行快照、节点进度与结果引用写入 `.tzhou/canvas/runs/`；旧数据库记录首次启动时迁移，确认文件可读后移除旧记录。会话关联、执行任务和审批仍复用 SQLite，媒体原件归作品或内容库管理，不内嵌到工作流 JSON。

图片、视频节点选择已启用的 MCP 生成插件和工具后，直接提交提示词，每组支持 1–8 项，不额外调用对话模型。可整组或按序号重新生成，历史结果保留；异步视频保存任务 ID，可继续查询，保存失败可单独重试而不重新生成。插件仅支持公开参考图链接时，本地参考图会提示不兼容，不会隐式上传。

默认原件保存到 **作品**；也可指定内容库目录或本地目录，生成后另外保存一份。图片支持预览、视频支持播放；显示的模型、比例、清晰度和时长仍受所选插件参数能力约束。

节点支持拖动缩放尺寸；图片预览可连续切换并记住上次位置。资源与图片节点均有保存位置入口，图片还可直接选择已有原件。节点插件按注册的配置 schema 和执行器扩展，详见 [画布节点插件](CANVAS_NODES.md)。

在普通会话中可直接要求「把这些素材放到画布上」「连接成工作流并运行选中的节点」。实际工具为 `canvas_list`、`canvas_read`、`canvas_apply`、`canvas_execute`、`canvas_cancel`；默认读取摘要和选区，节点详情按需获取。节点内部任务只能读取当前运行固定的画布，不能递归调度工作流。

### Excalidraw 白板

从 **创作 → 白板** 或画布顶部 **＋ 白板** 新建自由绘图白板。它与工作流共用列表和会话，但独立保存为白板类型。可以手动绘制矩形、菱形、椭圆、箭头、文字、手绘笔迹，导入图片、组合图形、设置样式、创建画框和使用素材库。界面语言及明暗主题沿用应用设置，编辑器与字体随应用打包。

右下角 **AI 助手** 可读取白板及选区，创建和修改可编辑图形，例如「画一个登录流程图」「把选中的图形横向排列」。使用当前会话的模型及权限；只读模式只讨论。AI 工具为 `whiteboard_create`、`whiteboard_read`、`whiteboard_apply`；按版本提交局部修改，过期请求会被拒绝，冲突会显示处理入口。手动编辑会自动保存，也可以按 Ctrl/⌘ S 保存；AI 图形修改可以通过编辑器的撤销和重做恢复。

编辑器左上角菜单支持导出 `.excalidraw`、PNG 和 SVG；顶部 **导入白板** 将 `.excalidraw` 文件导入为新白板，保留原画布。白板和本地图片随画布保存在应用数据目录。此集成提供本地白板与 AI 协作，不包含 excalidraw.com 的在线房间、实时多人协作服务器或云端账户服务。流程图中的箭头表示图形关系，不会执行工作流节点。
