# 同舟桌面界面重构

日期：2026-10-03。目标：让会话内容和下一步动作清晰可见，使各功能页遵循相同的尺寸、密度与反馈规则。

## 参考与取舍

不存在适合所有产品的“最佳 UI”。本轮对照可公开核验的官方产品资料，选择适合同舟的交互原则：

- [Linear：界面重构](https://linear.app/now/how-we-redesigned-the-linear-ui)：中性色界面、内容对比度、紧凑且对齐的导航与页面层级。
- [Cursor：紧凑会话](https://docs.cursor.com/en/agent/chat/compact)：减少辅助元素占用，过程按需展开，给会话正文更多空间。
- [Raycast：搜索和操作入口](https://www.raycast.com/blog/a-fresh-look-and-feel)：常用操作可搜索、键盘可到达，减少查找功能的成本。
- [Claude：独立内容面板](https://www.anthropic.com/news/artifacts)：把相关内容放在会话旁；同舟的项目文件与变更面板只在项目会话中出现，并允许关闭。

这些是交互依据，不照搬产品品牌、素材或专有实现。界面采用灰白底色与低饱和蓝灰强调色，同舟标志、应用图标与文档 Logo 统一使用蓝灰色；成功状态仍使用绿色，以浅色桌面界面为范围。

## 视觉规则

| 元素     | 规格与用途                                                               |
| -------- | ------------------------------------------------------------------------ |
| 正文     | 深中性色，聊天 15 px / 1.8 行高，长度约 800 px，支持选择复制             |
| 页面标题 | 22 px，直接使用功能名称，去掉重复的英文口号和大幅营销标题                |
| 元信息   | 11–12 px，保持可读；时间、模型、提示弱于正文                             |
| 控件     | 常规 34 px、紧凑操作至少 28 px；不会把文字压到 8–10 px                   |
| 色彩     | 白色内容面、浅灰导航、细边框；蓝灰色用于选中、主要按钮与焦点，标志色独立 |
| 状态     | 成功、运行、警告、失败有独立语义，配合文字，避免只靠颜色辨识             |
| 间距     | 4 / 8 / 12 / 16 / 24 / 32 px；导航密集、阅读舒展，避免处处大卡片         |
| 层级     | 当前内容 → 主要操作 → 状态 → 辅助说明；同一区域避免多个同等醒目的主按钮  |

## 功能盘点与改造

| 区域         | 调整                                             | 保留的功能                                         |
| ------------ | ------------------------------------------------ | -------------------------------------------------- |
| 应用框架     | 紧凑侧栏、可收起导航、搜索与快捷操作（Ctrl/⌘ K） | 项目分组、会话搜索、归档、设置入口                 |
| 普通聊天     | 移除常驻空项目栏、收敛欢迎页、正文与输入区对齐   | 模型切换、可空 Agent、补充、排队、复制、引用、分支 |
| 项目聊天     | 可收起文件面板、项目绑定标记清楚                 | 文件浏览、初始化说明、Git 变更、文件预览           |
| 会话过程     | 弱化容器、清楚的思考文本、工具组紧凑显示         | 每轮用时、阶段回复、停止、异常与审批               |
| 连接中心     | 紧凑列表、名称与状态优先、统一页签               | 模型订阅、模型选择、历史模式、账号授权和导入       |
| 服务与浏览器 | 添加入口与已连接列表分层，危险操作弱化           | GitHub / GitLab 授权、独立浏览器、Cookie 清理      |
| 渠道         | 配置与消息操作分组，规则可扫描，明确空状态       | 飞书扫码、Webhook、启停、通知规则、发送记录        |
| Agent 团队   | 紧凑卡片与指令摘要，空状态解释用途               | 创建、编辑、模型继承、单次选择、多 Agent 协作      |
| 插件与工具   | 核心能力、MCP、Skills 分页管理，清晰开关         | 电脑权限/自检、紧急停止、MCP 检查、Skill 导入      |
| 运行记录     | 状态筛选、标题搜索、紧凑统计与表格               | 跳转会话、实际 Token 用量与执行状态                |
| 设置         | 默认权限、账号入口、数据说明分层                 | 全局权限、应用全部、版本与存储说明                 |
| 弹窗与浮层   | 统一标题/表单/固定操作区、键盘关闭和焦点管理     | 认证、模型选择、Agent/MCP 配置、审批与错误反馈     |

## 验证

使用独立合成配置，在宽屏和较窄桌面窗口检查所有页面、弹窗、空状态与长内容；检验滚动、文本对比度、控件尺寸、键盘、面板恢复、聊天流与现有功能回归。截图及测试数据库只存放在忽略目录。本轮不更改用户模型、账号、权限或通知规则。
