# 微信 ClawBot

入口：资源与工具 → 机器人 → 微信 ClawBot机器人 → 扫码接入。

使用手机微信扫码并确认；如微信显示数字验证码，在同舟的同一授权面板输入。授权完成后自动连接，默认允许用户仅为扫码本人。使用模式与执行权限由右侧通用设置统一控制。

机器人页面左侧管理连接，右侧统一选择模型连接、模型、使用模式、执行权限和新建会话默认项目。所有平台共用设置；首次普通消息自动创建独立机器人对话，后续保持同一用户、同一聊天的上下文，不需要输入会话 ID 或命令。模型通过客户端工具查询会话标题与历史、定位目标并发起任务；有多个匹配时应询问用户。

默认“控制工作台”，可使用所有普通会话与工作台常规工具，包括内容库、作品、技能、定时任务和可由 Agent 修改的配置；其他用户的独立机器人聊天保持隔离。“仅聊天”只保留当前聊天上下文，不加载工作台、文件、外部插件或跨会话工具。扫码、凭据输入、扩大授权和审批仍需用户在本机处理。目标会话执行权限与模块执行权限取更严格者。共享设置修改会停止正在处理的机器人任务。

不再额外发送“收到，正在处理”。微信通过 `getconfig` / `sendtyping` 展示输入状态，完成或断开时停止；快速回答不补发迟到的输入提示。其他平台未接入输入状态时保持静默，最终回复照常发送。

## 统一通知

会话通过 `notificationTargets` 查询目标，`sendChannel` 即时发送，`saveNotificationRule` 设置指定运行的一次性完成通知。飞书和微信机器人复用已有凭据，不必再建渠道。定时任务的“完成后发送到”（`notificationTargetId`）在任务完成后由系统发送最终回答，支持只读任务，无需模型再执行一次发送。相同事件保留一条投递记录；失败或未确认不自动重发。

微信需要先向机器人发消息，主进程加密保存该用户最新的回复上下文；重新授权或更换账号会清除旧上下文。平台可能拒绝过期上下文，因此不保证任意时刻的微信主动发送。飞书需具备应用发消息权限且接收人处于应用可见范围。定时任务依赖本机同舟运行、网络与模型可用。

跨会话任务使用同一 Codex 核心；按来源关联运行结果，即使负责调度的对话已结束，目标会话结果仍回到原聊天。查询只读机器人也可以自然问答。微信目前支持私聊文本；图片、语音、文件与群聊尚未接入。

## 实现边界

- `openclaw-weixin-cli` 是安装器。同舟没有安装或运行另一套 OpenClaw 引擎；采用腾讯 `@tencent-weixin/openclaw-weixin` 2.4.9 的 iLink HTTP 协议，继续调用同舟已有任务执行核心。
- `services/bots/weixin/` 分别维护 HTTP 元数据与地址校验、扫码状态机、长轮询消息适配。不是企业微信的 WebSocket 模式。
- HTTP User-Agent 与 `base_info.bot_agent` 使用同舟身份；`iLink-App-Id=bot` 和客户端版本字段保持协议要求。
- Token 和收消息游标通过操作系统安全存储加密，前端只接收授权状态和非敏感账号信息。验证码只在待完成授权中暂存。区域跳转只接受 HTTPS 微信官方子域。
- 重连、删除与应用退出终止本地轮询。取消授权会忽略迟到的成功响应。登录失效后停止重试并提供“重新扫码”，同账号重新授权保留通用设置，完成后自动重连。
- `task-replies.ts` 按明确的 run ID 回传文本结果，发送前复核授权。不会订阅并转发整个工作台的会话内容。重启/重连会清除尚未发送的结果回传，历史结果仍保留在本机会话中。
- 入站消息以账号与完整消息 ID 去重，不自动重复执行任务。网络故障时回复不保证送达，可在同舟查看执行结果。当前不宣称实现 exactly-once 消息投递。

## 验证

`npx vitest run tests/integration/weixin-bots.test.ts` 覆盖协议身份、uint64 ID、地址限制、验证码、跳转、取消、文本上下文、游标和任务结果隔离。

`node scripts/testing/weixin-bots-smoke.mjs` 在独立测试配置中模拟微信服务，验证真实 IPC、凭据保存、验证码 UI、收发消息及重新授权；`--live` 仅取真实二维码并取消，不执行真实账号登录或发消息。

协议依据：[腾讯官方协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)、[官方插件源码](https://github.com/Tencent/openclaw-weixin)。真实账号扫码和与模型对话仍需登录后验收。

`tests/integration/bot-conversations.test.ts` 覆盖首次对话、跨平台共用设置、用户与群隔离、范围查询、禁止自提权、跨会话结果回传与撤销授权。
