# 模型能力与画布

在「模型 → 编辑连接 → 模型能力与画布」选择模型，分别标记文本生成、图片理解、图片生成、参考图编辑、视频生成、图生视频、视频首尾帧、音频生成及语音识别。图片理解不是图片生成；能力标记表示配置声明，不代表已通过真实服务验收。

未分类的旧模型保留对话入口。明确分类后，只有包含文本生成的模型出现在会话、Agent、文档助手及画布助手的模型列表；自动路由也检查此能力。语音识别目前仅作能力记录，没有新增转写节点。

## 生成工具绑定

为图片、视频或音频模型选择实际执行的媒体插件工具。当前生成走已有 MCP 媒体执行器，使用该插件的连接和认证，不会将模型连接的 API Key 自动复制给插件，也不会把聊天接口当成媒体接口。工具侧模型名称不同时，填写「工具中的模型 ID」。

工具目录明确列出模型 ID 时，可点击「采用工具目录中的能力匹配」；只匹配完全相同的 ID，不按模型名字猜测能力。若多个工具声明同一 ID，需要手动选择绑定。参考图、首尾帧等模式需用户确认模型支持，同时工具必须声明相应输入字段。

没有模型参数的工具、ComfyUI 工作流仍在画布直接选择。ComfyUI 的内部模型和节点由服务端工作流管理，不伪装成聊天模型。

## 画布使用

1. 点击图片、视频或音频节点，在「已配置的生成模型」选择对应模型。插件、工具和实际模型 ID 一起写入节点。
2. 不可用的工具、未绑定的模型或不支持当前模式的模型会显示原因，不能直接选中。
3. 连接参考图、首帧或尾帧后，执行器按实际输入再次检查模式和能力。AI 通过 `canvas_list.mediaModels` 读取同一目录，并使用条目返回的 `media` 字段配置节点。
4. 参数来自工具的真实 schema。修改工具绑定或移除模型后，旧节点要求重新选择，避免继续查询被转到另一服务。切回「直接选择插件与工具」可独立配置。
5. 沿用现有审批、运行记录、逐项重试、原件保存及任务 ID 恢复。标记能力和保存配置本身不调用生成接口。

项目包不携带模型连接/插件绑定或凭据；导入另一客户端后重新选择。当前不是 infinite-canvas 的模型配置或远程节点插件兼容层。

## 内容组织

内容库保留通用目录、类型和标签；人物/场景/道具等仅为漫剧技能的项目约定。文档「更多操作 → 内容属性与来源」可编辑目录、自定义类型、标签和来源列表。目录移动保留稳定文档 ID。单独修改分类保留原来源版本，修改来源列表会采用所选来源的当前版本。导入原件保持不可编辑，可另存副本维护加工内容。

通过隔离测试的合成 MCP 图片生成、目录/标签筛选及来源冲突用例验证，不使用用户账号或付费生成接口。
