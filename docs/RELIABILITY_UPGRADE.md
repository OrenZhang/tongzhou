## 尚需真实环境验收

第三方真人授权、机器人/邮件真实送达、各订阅模型长任务与弱网矩阵、macOS 实机仍需相应账号或环境；本轮没有把替身服务算作真实平台通过。Windows/macOS 签名证书、公证和自动更新分发渠道也没有凭空完成。本轮提供版本查询和发布配置，不宣称已实现静默自动更新。

文本检查点仅处理范围内的小型文本文件，排除依赖、构建产物、密钥和二进制；并发修改可能进入同一轮差异，界面已标明。终端日志为有界缓冲，备份当前上限 256 MB。项目内容、浏览器下载与系统登录状态需另行保存。本版本仍是开发预览，不宣称与 Codex 全能力等价。
