# 同舟 v0.1.1

首个正式版 v0.1.0 之后的更新版本。

- 插件可检测并启用本机已登录的 GitHub 账号；支持检测官方与自建 GitLab 本机账号，并在连接对话框中展示。
- 支持编辑并重发未回复的消息，操作按钮更紧凑。
- 工作区文件预览支持渲染 Markdown 文档；原生工具记录显示操作名称。
- 权限调整立即作用于运行中的任务；应用升级时准确显示当前权限；审批项合并为紧凑单行。
- 模型管理移入设置；缩短模型标签；侧栏导航分组与间距优化。
- 增加各平台电脑权限引导与 macOS 品牌展示；macOS 权限面板不再抢占焦点。
- 修复 macOS 窗口识别并移除光标遮罩；macOS Dock 图标尺寸与原生应用对齐。
- 修复 Kimi 订阅令牌在鉴权检查与推理前的续期；支持 Kimi 订阅默认模型协议。
- 会话删除前必须先归档，避免误删。
- 重构工作区模块并统一 Codex 执行路径。

## 安装包

Windows 使用 `win-x64.exe`；Apple Silicon 使用 `mac-arm64.dmg`；Intel Mac 使用 `mac-x64.dmg`。ZIP 用于 macOS 更新通道，校验文件为 `SHA256SUMS-*`。

没有配置发布证书时，安装包不具备发行者签名。macOS 未签名版本仅支持下载新版安装包；配置 Developer ID 与公证凭据后，新发布的签名版本才启用自动安装。

已安装 v0.1.0 的用户可通过应用内更新或下载本版安装包升级；请勿删除应用数据目录。仍在使用 v0.5.8 开发预览的用户需要手动安装正式版，自动更新不会将较高版本号降级。
