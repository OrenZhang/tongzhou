# 同舟 v1.0.0

以当前格式作为全新版本基线，统一执行核心、本地文件存储和渠道能力。

- 所有模型共用 Codex 执行核心，工具调用、任务继续、上下文压缩和线程恢复沿同一条执行路径。
- 文档、目录、原件、附件、作品及修订记录保存在本地 .tzhou；SQLite 保存会话、配置和运行记录。文档原子写入后即视为保存成功，派生索引失败不会把已保存结果报成失败。
- 删除旧数据库迁移、旧目录搬迁、SQLite 文档转文件、旧归档状态转换、历史记忆转换和旧主题配置读取。仅支持当前数据格式，不自动转换历史版本数据。
- 记忆开关统一使用内置自动任务规则，保留中断恢复、证据校验、重试和去重。
- 渠道统一管理微信 ClawBot、飞书、企业微信、钉钉和邮件；机器人接入与通知目标共用渠道页面。模型及执行设置统一管理，支持通过客户端工具发送消息、设置完成提醒和定时通知。
- 删除重复的飞书通知渠道入站实现，接收与会话操作统一由机器人服务负责；移除浏览器账号模块。
- 内容库使用目录文件树，文件在侧边工作区打开；文档聊天输入固定在底部，支持回车发送，编辑与审批交互更紧凑。
- 工作区支持 Markdown、HTML 及交互内容预览；导航与服务图标使用适度配色，下载提示改为蓝色圆形箭头，Windows 快捷方式显示“同舟”。
- 发布流程保留版本检查、自动测试、打包验证和校验文件，删除初始版本替换与历史预览清理脚本。

## 安装包

Windows 使用 win-x64.exe；Apple Silicon 使用 mac-arm64.dmg；Intel Mac 使用 mac-x64.dmg。macOS ZIP 用于更新通道，各平台校验文件为 SHA256SUMS-\*。

未配置发布证书时，安装包不具备发行者签名。macOS 未签名版本提供新版安装包下载；配置 Developer ID 与公证凭据后，签名版本才启用自动安装。
