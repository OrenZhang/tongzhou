# 同舟 v1.0.1

优化任务管理和导航，让列表更紧凑、入口更清晰。

- 自动化任务改为表格，集中展示任务名称、类型、触发方式、状态、下次执行和操作。
- 执行记录改为紧凑表格，点击记录展开对应结果，保留筛选、重试、停止和查看关联内容等操作。
- 模型移至“资源与工具”末尾，删除设置中的重复模型和渠道入口。
- 超过三项的侧栏分组默认显示首尾两项，省略号与图标列对齐；标题整行可展开或收起，省略号整行可展开。
- 从搜索进入隐藏功能时，侧栏自动展开并显示当前位置。
- 面包屑支持点击返回，网络配置的“返回设置”按钮移至标题右侧；可点击文字使用更清晰的蓝色提示。

## 安装包

Windows 使用 win-x64.exe；Apple Silicon 使用 mac-arm64.dmg；Intel Mac 使用 mac-x64.dmg。macOS ZIP 用于更新通道，各平台校验文件为 SHA256SUMS-\*。

未配置发布证书时，安装包不具备发行者签名。macOS 未签名版本提供新版安装包下载；配置 Developer ID 与公证凭据后，签名版本才启用自动安装。
