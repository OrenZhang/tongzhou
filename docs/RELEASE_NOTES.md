# 同舟 v0.1.0

同舟的首个正式版本，从 v0.1.0 开始编号。

- 多模型会话与 Agent 协作，支持项目、Git 工作树和内置终端。
- 会话输入框集中显示项目、实际执行目录、Git 分支与权限，模型与连接合并选择。
- 右侧工作区统一文件预览、任务审阅和终端；支持调宽、底部停靠与逐会话状态恢复。
- 点击会话标题直接编辑名称；支持 Enter/失焦保存、Esc 取消。侧栏图标悬浮只变色。
- 任务结果可直接打开对应改动与验证记录，项目文件链接支持定位源码行。
- 插件按核心能力、内置插件与个人插件组织，支持应用、MCP 和技能分类。
- 内置 GitHub、GitLab 等应用连接，按账号授权与会话权限调用工具。
- 内置「技能创建」技能：在会话中描述工作方法，创建后直接保存到个人插件；支持附属参考文件与后续修改。
- 本地知识与记忆整理、工作数据加密备份、通知渠道及版本更新。
- 应用请求统一使用 Tongzhou 版本标识。

## 安装包

Windows 使用 `win-x64.exe`；Apple Silicon 使用 `mac-arm64.dmg`；Intel Mac 使用 `mac-x64.dmg`。ZIP 用于 macOS 更新通道，校验文件为 `SHA256SUMS-*`。

没有配置发布证书时，安装包不具备发行者签名。macOS 未签名版本仅支持下载新版安装包；配置 Developer ID 与公证凭据后，新发布的签名版本才启用自动安装。

此前的 v0.5.8 是开发预览编号，本次正式版重新从 v0.1.0 开始。已安装开发预览的用户需要手动安装本版本，自动更新不会将较高版本号降级；请勿删除应用数据目录。源码启动的开发预览需要先安装正式包，才能使用后续更新通道。

本次继续使用 v0.1.0 并替换同版本安装包。已安装较早 v0.1.0 安装包的用户需要重新下载并安装，自动更新不会将同版本识别为新版本。
